Antes de formatear: respaldo

// El paso que no puedes saltarte

Formatear borra TODO el disco. Verifica que respaldaste tus datos antes de continuar. No hay forma de revertir un formateo completo sin herramientas de recuperacion especializadas.
1 Que respaldar
Documentos, fotos, videos, musica, proyectos, descargas importantes, marcadores del navegador, correo configurado, contrasenas guardadas, claves de licencia, configuraciones de programas y carpetas del Escritorio, Documentos, Imagenes y Descargas.
2 Donde guardarlo
Disco externo, USB grande, nube (Google Drive, OneDrive, Dropbox) o un segundo disco. La regla 3-2-1: 3 copias, en 2 soportes distintos, 1 fuera de tu casa. Ver guia de plan de respaldo.
3 Verificar tu licencia de Windows
En equipos modernos la licencia esta enlazada a tu cuenta de Microsoft (activacion digital) o grabada en el firmware (OEM). Revisa en Configuracion > Sistema > Activacion si dice "Windows esta activado". Si es asi, al reinstalar se reactivara solo.
4 Descargar los drivers de antemano
En laptops del fabricante (HP, Dell, Lenovo, Asus, Acer) descarga de antemano los drivers de chipset, red (Wi-Fi/Ethernet) y grafica a un USB. Sin driver de red no podras bajar el resto despues de instalar.
cmd · ver la clave de Windows (OEM / actual)
# Ver la clave de producto instalada (ejecutar como Administrador)
  > wmic path SoftwareLicensingService get OA3xOriginalProductKey

Paso 1: Crear el USB booteable

// Windows y Linux

Necesitas un USB de 8 GB minimo (16 GB recomendado para Windows 11). El USB se formateara por completo: no debe contener nada importante.

Opcion A: Media Creation Tool (oficial, facil)
  1. Entra a microsoft.com/software-download/windows11 (o /windows10).
  2. Descarga la Media Creation Tool y ejecutala.
  3. Acepta la licencia y elige "Crear medios de instalacion (USB)" .
  4. Selecciona idioma y edicion, elige el USB y deja que descargue y lo configure (puede tardar 20-60 min).
Es la via mas segura: la herramienta descarga la ISO oficial y configura el USB en el formato correcto (FAT32 + GPT para UEFI).
Opcion B: Rufus (ISO, mas control)
  1. Descarga la ISO de Windows desde la pagina de Microsoft (usando el selector de descarga de la ISO) o la ISO de Ubuntu desde ubuntu.com.
  2. Descarga Rufus (rufus.ie), versione portable si quieres.
  3. Conecta el USB y seleccionalo en Rufus, elige la ISO y configura:
OpcionValor recomendado
Esquema de particionGPT
Sistema destinoUEFI (sin CSM)
Sistema de archivosFAT32 (Windows); en ISO mayores a 4 GB usa NTFS o exFAT
Tamano clusterPor defecto
MBR vs GPT: si tu PC es moderno (UEFI), usa GPT. Solo usa MBR si tienes una placa antigua con BIOS legacy o un equipo 32-bit.
Opcion C: Ventoy (multi-ISO)

Ventoy convierte el USB en un cargador multiple: solo copias las ISOs al USB (Windows, Ubuntu, herramientas de rescate) y al arrancar eliges cual cargar. Ideal para tecnicos que llevan varias ISOs en un solo USB. Ver guia detallada de USB booteable.

Paso 2: Arrancar desde el USB

// BIOS / UEFI y menu de arranque

1 Conecta el USB y reinicia
Con el USB insertado, reinicia el equipo y pulsa repetidamente la tecla de arranque o de BIOS apenas encienda.
2 Elige el metodo de entrada
Menu de arranque (boot menu): F11, F12, F8 o Esc (segun fabricante) te deja elegir el USB sin tocar la configuracion. BIOS/UEFI: DEL o F2 para entrar y cambiar el orden de arranque.

Ajustes recomendados en la BIOS
  • Boot mode: UEFI (no Legacy/CSM) en equipos modernos.
  • Secure Boot: dejalo activado para Windows 11; desactivalo solo si la instalacion falla o usas Linux con drivers propietarios.
  • Fast Boot: desactivalo temporalmente si el USB no aparece.
  • TPM: en la mayoria ya viene activo; Windows 11 lo exige.
Si el USB no aparece en el menu de arranque, prueba: otro puerto USB (usa un puerto directo del motherboard, no un hub), desactiva Fast Boot, y verifica que el USB este creado en GPT/UEFI.

Paso 3: Instalar Windows 10/11

// Particionar y formatear el disco

1 Arranca el instalador
Elige tu idioma y haz clic en "Instalar ahora". Si el equipo tenia un sistema anterior, puedes elegir "Reparar" si solo quieres recuperar el sistema sin perder datos.
2 Ingresa la clave o continua
Si es una licencia digital u OEM, selecciona "No tengo una clave" y se reactivara luego. Selecciona la edicion correcta (Home o Pro) segun tu licencia.
3 Elige instalacion personalizada
Selecciona "Instalacion personalizada: solo Windows (avanzado)". Ahi ves la lista de discos y particiones.
4 Borra las particiones del disco destino
MUY IMPORTANTE: identifica el disco correcto (por tamano). Selecciona cada particion de ese disco y pulsa "Eliminar" hasta dejar "Espacio no asignado". No borres discos con tus datos respaldados. En laptops suele haber particiones de recuperacion y EFI: borrar todas es correcto si ya respaldaste.
5 Instala en el espacio no asignado
Selecciona "Espacio no asignado" y pulsa "Siguiente". Windows crea solo las particiones necesarias (EFI, MSR, Recuperacion y Principal) y formatea en NTFS automaticamente. Si quieres separar datos, crea particiones extra despues con Administrador de discos.
Consejo de particionado: si quieres mantener tus datos separados del sistema, crea C: (100-150 GB para Windows y programas) y deja el resto como D: para datos. Asi, futuros formateos solo tocan C:.
Configuracion inicial (primera conexion)
  • Region e idioma: elige tu pais y la distribucion del teclado (en espanol suele ser "Latin America" o "Espana").
  • Cuenta: si quieres una cuenta local, desconecta la red (cable y WiFi) y elige "Opciones de conexion" > "Cuenta local". Windows 11 Home a veces lo oculta: usa Shift+F10 y ejecuta oobe\bypassnro para saltar el requisito de internet.
  • Privacidad: desactiva lo que no quieras compartir (ubicacion, diagnostico, anuncios).
  • Primer arranque: el escritorio puede tardar varios minutos configurandose. Se reinicia una o dos veces solo.
cmd · saltar requisito de internet (Windows 11 Home)
# En la pantalla de "Escribamos tus datos": Shift+F10 y ejecuta
  > oobe\bypassnro
  # Se reinicia y aparece "No tengo acceso a internet" -> Continuar con instalacion limitada

Paso alterno: Instalar Ubuntu (Linux)

// Si quieres un sistema libre o recuperar un PC lento

  1. Descarga la ISO de ubuntu.com/download y crea el USB con Rufus (GPT/UEFI) o Ventoy.
  2. Arranca desde el USB y elige "Probar o instalar Ubuntu".
  3. Elige "Borrar disco e instalar Ubuntu" (reemplaza todo) o "Instalar Ubuntu junto a Windows" (crea doble arranque).
  4. En el paso de particiones, puedes dejar la opcion automatica. Si quieres control manual, usa Ext4 para la raiz (/) y swap como area de intercambio (equivale a la memoria virtual).
  5. Crea tu usuario y espera la instalacion. Al terminar, reinicia y quita el USB.
Doble arranque: instala Ubuntu DESPUES de Windows (o primero desactiva Windows Fast Startup). Linux instalado antes que Windows suele perder el arranque al instalar Windows despues.

Paso 4: Que hacer despues de formatear (paso a paso)

// La secuencia completa para dejar el equipo al dia

1 Primer arranque: region, cuenta y privacidad
Configura idioma, teclado y crea tu cuenta. Si elegiste cuenta local, anota bien el nombre y la contrasena. Decide que opciones de privacidad quieres mantener. Espera a que el escritorio termine de configurarse (puede tardar varios minutos y reiniciarse).
2 Verifica la conexion a internet
Conecta por cable o WiFi y comprueba que navegas. Si no hay red, es que falta el driver de red: instala el que bajaste antes en el USB (o conecta el cable Ethernet). Sin internet no podras actualizar ni descargar el resto.
3 Ejecuta Windows Update completo
Configuracion > Windows Update > "Buscar actualizaciones". Instala todo y reinicia cuantas veces pida. Repite hasta que diga "No hay actualizaciones disponibles". Este paso tambien baja drivers basicos y parches de seguridad.
4 Instala los drivers oficiales (en este orden)
Chipset (sitio del fabricante de la placa o laptop) → Grafica (NVIDIA, AMD o Intel) → Red (Wi-Fi/Ethernet) → Audio → Opcionales (Bluetooth, SATA/RAID, USB, touchpad en laptop). Reinicia entre grupos si el sistema lo pide.
5 Activa Windows
Configuracion > Sistema > Activacion. Con licencia digital se reactiva al iniciar sesion con tu cuenta Microsoft. Si no, introduce la clave en "Cambiar clave de producto". Verifica que diga "Windows esta activado".
6 Revisa el Administrador de dispositivos
Clic derecho en el boton Inicio > Administrador de dispositivos. No debe haber iconos amarillos (!). Si los hay, es un driver pendiente: instala el correspondiente y reinicia.
7 Instala los programas esenciales
Navegador, paquete ofimatico, compresor y reproductor como minimo. Ve a la seccion Programas esenciales de esta guia y elige por categoria.
8 Restaura tus datos
Copia tus archivos respaldados, importa marcadores y contrasenas del navegador, y vuelve a configurar tu correo. No borres el respaldo hasta confirmar que todo esta y funciona.
9 Verifica temperaturas y rendimiento
Con HWiNFO, HWMonitor o MSI Afterburner revisa temperaturas en reposo y en carga. Un CPU/GPU al 100% no debe pasar de los 85-90°C. Si algo se calienta de mas, revisa la pasta termica y el flujo de aire. Ver software de diagnostico.
10 Crea un punto de restauracion
Con el sistema recien instalado es el mejor momento para tener una "foto limpia": activa Proteccion del sistema en C: y crea un punto de restauracion. Asi podras volver a este estado si algo falla. Para algo mas completo, haz una imagen de disco con Macrium Reflect o Rescuezilla.
11 Desinstala bloatware y limpia el inicio
Elimina programas que no usaras (juegos de prueba, aplicaciones preinstaladas) y revisa que no se auto-inicien cosas innecesarias (Ctrl+Shift+Esc > Inicio). Ver guia de optimizacion.
12 Configura tu respaldo automatico
Programa copias de seguridad de tus datos (OneDrive, historial de archivos, o un respaldo local). El mejor momento para configurarlo es ahora, con el sistema limpio. Ver plan de respaldo.
Evita los "Driver Booster" y actualizadores genericos: instalan drivers incorrectos o con adware. Descarga siempre desde el sitio oficial del fabricante.

Instalar varios programas de golpe

Ninite: marca las apps que quieras en ninite.com, descarga el instalador y el se encarga de todo (sin adware ni barras). Perfecto justo despues de formatear.

winget: el instalador de paquetes oficial de Windows funciona desde PowerShell. Ejemplos:

powershell · instalar programas con winget
# Instalar de uno en uno
  > winget install --id Mozilla.Firefox -e
  > winget install --id VideoLAN.VLC -e
  # Varios a la vez
  > winget install Mozilla.Firefox VideoLAN.VLC 7zip.7zip --accept-package-agreements --accept-source-agreements
  # Buscar un paquete por nombre
  > winget search notepad
Winget ya esta en Windows 11 y en Windows 10 recientes (App Installer). Si no lo tienes, instala "App Installer" desde la Microsoft Store.

Programas esenciales en Linux (Ubuntu)

Ubuntu ya trae navegador (Firefox), ofimatica (LibreOffice) y reproductor incluidos. Instala el resto desde la Tienda de software o con apt:

bash · programas esenciales en Ubuntu
# Actualizar el sistema
  $ sudo apt update && sudo apt upgrade -y
  # Paquetes recomendados tras instalar
  $ sudo apt install -y vlc gimp htop neofetch timeshift
  # Timeshift crea instantaneas del sistema (como puntos de restauracion)
  • GIMP: edicion de imagenes (alternativa a Photoshop).
  • VLC: reproductor multimedia.
  • htop: monitor de procesos desde terminal.
  • Timeshift: instantaneas del sistema para poder volver atras.
  • Visual Studio Code, Chrome, Discord: se instalan desde los .deb oficiales o Snap/Flatpak.
Que evitar instalar: "optimizadores", "aceleradores de RAM", "limpiadores de registro", barras de busqueda y versiones pirata de programas. Suelen traer adware, ralentizan el equipo y muchas veces son malware. Windows moderno se mantiene solo; un antivirus real y sentido comun bastan.

Notas especificas para laptop

// Diferente a una PC de escritorio

  • Bateria: con la laptop enchufada durante toda la instalacion para evitar cortes por apagado.
  • Teclas de arranque: usa la tabla de arriba por fabricante (HP F9, Dell F12, Lenovo F12, Acer F12). En algunas laptops el boot menu esta deshabilitado y hay que activarlo en BIOS.
  • Drivers OEM: las laptops usan drivers especificos del fabricante. Descargalos ANTES desde el soporte del fabricante (chipset, grafica, Wi-Fi, teclado/panel tactil, audio) y guardalos en un USB. Sin el driver de Wi-Fi la laptop queda sin red tras instalar.
  • Modulos soldados: el formateo no toca el hardware, pero verifica cuanta RAM tiene antes de exigir mas a Windows 11.
  • Particion de recuperacion: al eliminar todas las particiones pierdes la "Recuperacion" del fabricante. Asegurate de haber creado tu propio USB o la ISO antes.
  • BitLocker: si el disco estaba cifrado y la laptop pide clave de recuperacion al arrancar desde USB, necesitas la clave de 48 digitos (guardada en tu cuenta Microsoft). Si no la tienes, los datos se pierden.

Alternativa sin USB: Restablecer este PC

// Cuando Windows aun arranca

Si Windows inicia correctamente pero quieres dejarlo limpio sin crear un USB, usa la funcion integrada:

  1. Configuracion > Sistema > Recuperacion.
  2. En "Restablecer este PC" pulsa "Restablecer PC".
  3. Elige "Quitar todo" (borra programas, configuracion y archivos) o "Conservar mis archivos" (quita programas y configuracion, mantiene tus archivos personales).
  4. Elige la instalacion de Windows: local o en la nube (descarga los archivos de instalacion de Microsoft).
  5. Confirma y espera: el equipo se reinicia, formatea y reinstala Windows.
"Quitar todo" no es borrado seguro: los datos quedan recuperables con software. Si vas a vender o regalar el equipo, usa borrado seguro antes de reinstalar.
Windows no arranca? Entra al entorno de recuperacion (WinRE) reiniciando 3 veces durante el inicio, o con el USB en "Reparar el equipo". Ahí puedes usar "Restablecer", "Restaurar sistema" o "Solucionar problemas".

Preguntas frecuentes

// Dudas comunes al formatear

Cuanto tarda en formatear e instalar Windows?

De 15 a 40 minutos la instalacion base en un SSD, mas los reinicios y las actualizaciones (que pueden sumar otra hora). En un HDD viejo puede tardar el doble.

Perdere mi Windows si lo formateo?

No, si la licencia es digital/OEM: se reactiva automaticamente al reinstalar la misma edicion (Home/Pro) en el mismo equipo. Guarda tu clave antes por si acaso con wmic path SoftwareLicensingService get OA3xOriginalProductKey.

Formatear hace mas rapido mi PC?

En equipos con muchos programas y malware, si: deja el sistema limpio y sin procesos de fondo. Pero si el equipo es viejo, la mayor mejora es cambiar el disco HDD por un SSD. Un formateo no arregla hardware fallando (RAM, disco fisico o bateria).

Que diferencia hay entre "formatear" y "reinstalar"?

Formatear borra el contenido de la particion (prepara el sistema de archivos). Reinstalar copia el sistema operativo nuevo. En la practica se usan juntos: el instalador de Windows te deja eliminar particiones (formatear) y en ese espacio instala el sistema nuevo.

Debo desconectar el disco de datos al formatear?

Si tienes un segundo disco con datos importantes, es lo mas seguro: desconectalo fisicamente o identificalo con mucha atencion por tamano en el instalador. Un error al seleccionar disco borra todo.
