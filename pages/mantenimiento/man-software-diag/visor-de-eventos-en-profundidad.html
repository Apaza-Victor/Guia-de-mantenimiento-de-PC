Visor de Eventos en Profundidad

Mantenimiento · Software de Diagnostico — Leccion 4 de 5

Inicio/Mantenimiento/Software de Diagnostico/Visor de Eventos en Profundidad

El Visor de Eventos registra todo lo que ocurre en Windows y es la primera fuente de verdad ante BSOD, reinicios o servicios que fallan. Abrelo con eventvwr.msc (Win+R o desde el menu inicio).

  • Logs a revisar: "Registros de Windows → Sistema" (errores de hardware, controladores y servicios) y "Registros de Windows → Aplicaciones" (errores de programas).
  • Event ID 41 (Kernel-Power): el equipo se apago sin un apagado limpio (corte de energia, PSU o crash de hardware). Muy comun tras un BSOD o un apagon.
  • Event ID 1001 (BugCheck): se produjo un BSOD. Filtra este ID para ver la frecuencia exacta de las pantallas azules.
  • Event ID 6008: apagado inesperado detectado en el ultimo arranque (suele acompanar al 41).
  • Event ID 7000/7001: un servicio no pudo iniciarse o depende de otro que fallo. Tipico de drivers rotos tras una actualizacion.
  • Filtros y vistas personalizadas: crea una "Vista personalizada" por nivel de error critico y por intervalo para no leer el log completo cada vez.
  • Que ignorar: errores de discos externos desconectados bruscamente (Event ID 157 Kernel-Disk), cortes de WLAN intermitentes y errores de servicios de telemetria que no afectan el sistema.
powershell · consultar eventos por ID 
# Ultimos 50 errores del Sistema en las ultimas 24 horas
  > Get-WinEvent -FilterHashtable @{LogName='System'; Level=1,2; StartTime=(Get-Date).AddDays(-1)} -MaxEvents 50

  # Buscar BSOD (Event ID 1001) en el registro Sistema
  > Get-WinEvent -FilterHashtable @{LogName='System'; Id=1001} -MaxEvents 10

  # Errores WHEA de hardware (Provider WHEA-Logger)
  > Get-WinEvent -FilterHashtable @{LogName='System'; ProviderName='Microsoft-Windows-WHEA-Logger'} -MaxEvents 10
Practica: cuando diagnostiques un reinicio misterioso, filtra por Event ID 41 y 1001 en las ultimas 2 semanas y compara las horas con tu historial de BSOD. La correlacion de horas resuelve la mayoria de los casos.
