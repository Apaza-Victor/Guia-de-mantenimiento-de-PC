Borrado Seguro

// Borrar no es eliminar: la data sigue ahi

Concepto clave: formatear o vaciar la papelera SOLO marca el espacio como libre. Con las herramientas adecuadas, los datos se pueden recuperar. El borrado seguro sobrescribe fisicamente la informacion.

Recomendacion realista: para uso domestico y laboral normal, 1 pase de sobrescritura + verificar es mas que suficiente. Las multiples pasadas eran para HDD analogicos antiguos; en discos modernos no aportan seguridad extra.
SSD — borrado criptografico (Secure Erase)
El metodo correcto para discos de estado solido
▼
  • Los SSD usan wear leveling: los datos se escriben repartidos, por lo que sobrescribir "toda la unidad" no garantiza borrar todo.
  • El metodo oficial es Secure Erase del propio SSD (comando ATA): borra todas las celdas y la clave de cifrado.
  • Desde Windows: herramientas del fabricante (Samsung Magician, Crucial Storage Executive, Kingston SSD Manager) suelen tenerlo.
  • Alternativa universal: hdparm --security-erase en Linux (con el SSD desmontado y la unidad apagada correctamente).
  • Si el SSD tiene cifrado por hardware, borrar la clave (crypto erase) es suficiente e instantaneo.
Ojo: NUNCA uses un "secure erase" en el disco donde esta el sistema operativo en uso, ni apagues el PC durante el proceso. Interrumpirlo puede dejar el SSD inutilizable. Respaldalo todo antes.
HDD — sobrescritura con DBAN / Eraser
El metodo para discos mecanicos
▼
  1. Descarga DBAN (Darik's Boot and Nuke) o usa Eraser desde Windows para unidades en uso.
  2. Grabalo en un USB o CD de arranque (Rufus).
  3. Arranca desde el medio, selecciona el disco a borrar (CUIDADO: solo el que quieres eliminar) y elige "Quick Erase" (1 pase) o "DoD Short" (3 pasadas).
  4. Deja correr: en un HDD de 1TB con 3 pasadas puede tardar varias horas.
  5. Verifica al final que el disco arranca "vacio" (sin tabla de particiones).
Verificacion: tras sobrescribir, intenta recuperar cualquier archivo con Recuva: si aparece vacio, el borrado fue efectivo. Herramientas como CrystalDiskInfo te confirman que el disco sigue sano.
Destruccion fisica — ultimo recurso
Cuando la informacion no puede salir de ahi
▼
  • Trituradora industrial: las particulas < 2mm hacen irrecuperables los platos.
  • Perforar los platos (varios agujeros en la zona de datos) es accesible para el tecnico; no basta con un solo agujero.
  • Desmagnetizador (degausser): solo para HDD (magnetiza los platos). Inutil en SSD.
  • SSD: triturar los chips NAND directamente, o el crypto erase es suficiente para la mayoria de usos.
Para el tecnico: ofrece al cliente la opcion segun el valor de la informacion. En laptops/PC de empresa se suele exigir certificacion de destruccion (documento del proveedor de destruccion con numero de serie).
