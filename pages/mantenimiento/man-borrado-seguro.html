Borrado Seguro

// Borrar no es eliminar: la data sigue ahi

Concepto clave: formatear o vaciar la papelera SOLO marca el espacio como libre. Con las herramientas adecuadas, los datos se pueden recuperar. El borrado seguro sobrescribe fisicamente la informacion.

El metodo correcto para discos de estado solido
HDD — sobrescritura con DBAN / Eraser
