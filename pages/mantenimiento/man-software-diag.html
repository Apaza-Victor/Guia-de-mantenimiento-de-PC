Software de Diagnostico

// Herramientas para diagnosticar tu PC

Siempre descarga software de sitios oficiales para evitar malware. Verifica la URL antes de descargar.
HWMonitor

Monitoreo de temperaturas, voltajes y RPM de ventiladores en tiempo real. Soporta la mayoria de sensores del motherboard.

Temperaturas
CrystalDiskInfo

Muestra la salud de discos duros y SSDs mediante datos S.M.A.R.T. Alerta de sectores reasignados y temperatura.

Discos
Memtest86

Test exhaustivo de memoria RAM. Se ejecuta desde USB booteable antes de cargar el SO. Requiere multiples pasadas.

RAM
CPU-Z

Informacion detallada del procesador, chipset, RAM (frecuencia, timings, canal) y motherboard.

CPU / RAM
GPU-Z

Estadisticas completas de la tarjeta grafica: GPU, VRAM, clock speeds, temperatura y sensores en tiempo real.

GPU
FurMark

Test de estres para GPU (burn-in test). Genera carga maxima para verificar estabilidad y temperaturas extremas.

GPU Stress
Prime95

Test de estres para CPU. Los "Small FFTs" generan calor maximo. Ideal para probar estabilidad despues de overclock.

CPU Stress
AIDA64

Diagnostico completo del sistema: hardware, software, sensores, benchmarks. Suite profesional de diagnostico.

Completo
Event Viewer

Registro de eventos de Windows (eventvwr.msc). Errores criticos, warnings y logs del sistema y aplicaciones.

Windows
CrystalDiskMark

Benchmark de velocidad de discos. Mide lectura y escritura secuencial y aleatoria (4K). Compara SSD vs HDD.

Benchmark
HWiNFO

Considerado el toolset mas completo de informacion de hardware. Usado por fabricantes y profesionales. Soporta los componentes mas recientes antes que la mayoria de programas competidores. No envia datos por red.

Monitoreo · Gratuito
MSI Afterburner

Herramienta de overclocking y monitoreo de GPU compatible con cualquier marca (no solo MSI). Permite personalizar curvas de ventilador, mostrar overlay en juegos y exportar registros de temperatura.

GPU · Gratuito
Cinebench R23/2024

El benchmark de CPU mas respetado. Usa el motor de renderizado de Cinema 4D para medir rendimiento single-core y multi-core. Sus resultados son directamente comparables en la base de datos online de Maxon.

CPU · Benchmark
3DMark

Benchmark de rendimiento de GPU con escenas de juego reales. Mide FPS, puntajes comparables y estabilidad. Incluye pruebas ray tracing y pruebas de carga para verificar que el sistema esta bien balanceado.

GPU · Benchmark
HD Tune

Verifica la salud de discos duros con pruebas SMART completas, mapa de errores y pruebas de transferencia. Permite detectar sectores defectuosos antes de que el disco falle completamente.

Disco · Diagnostico
ThrottleStop

Herramienta avanzada para monitorear y controlar el throttling del CPU Intel. Permite ajustar voltajes, multiplicadores y desactivar limitaciones de potencia para maximizar el rendimiento.

CPU · Avanzado
OBS Studio

Software de grabacion y streaming de pantalla. Util para capturar problemas visuales, artefactos de GPU o documentar procedimientos de diagnostico durante sesiones de soporte remoto.

Grabacion · Open Source
Discord

Servidores de hardware activos en espanol: PC Master Race ES, HardZone Discord. Ventaja: respuesta en tiempo real para dudas de compatibilidad, overclocking y ayuda tecnica vs foros donde puede tomar horas.

Comunidad · Gratuito
UserBenchmark

Comparador online de rendimiento de CPU, GPU, RAM y SSD con millones de resultados reales de usuarios. Util para valorar si un sistema rinde segun lo esperado para su hardware.

Benchmark · Web
Kit minimo recomendado: HWMonitor + CPU-Z + CrystalDiskInfo + MemTest86 (USB booteable) + DDU. Con estas 5 herramientas puedes diagnosticar el 90% de los problemas comunes de hardware.

Orden recomendado: empieza por lo mas barato de descartar — temperatura (HWMonitor) y disco (CrystalDiskInfo) — antes de lanzar tests de estres. Un test de estres con una falla termica previa puede danar el equipo.
Comandos de diagnostico integrados en Windows
cmd / powershell · ejecutar como Administrador 
# INTEGRIDAD DE ARCHIVOS DEL SISTEMA
  > sfc /scannow                        # Escanea y repara archivos de sistema
  > DISM /Online /Cleanup-Image /CheckHealth
  > DISM /Online /Cleanup-Image /RestoreHealth

  # VERIFICAR DISCO (reinicia si C: esta en uso)
  > chkdsk C: /f /r /x              # /f=corregir /r=sectores /x=forzar desmontaje

  # REPORTE DE BATERIA (portatiles)
  > powercfg /batteryreport /output C:\battery.html

  # TEST DE MEMORIA (programa reinicio)
  > mdsched.exe

  # INFORMACION DEL SISTEMA
  > systeminfo
  > msinfo32                           # GUI completa con hardware y software

  # HARDWARE DETALLADO (WMIC)
  > wmic cpu get Name,NumberOfCores,MaxClockSpeed
  > wmic memorychip get Capacity,Speed,MemoryType
  > wmic diskdrive get Model,Size,Status

  # EVENTOS DE ERROR RECIENTES (PowerShell)
  > Get-EventLog -LogName System -EntryType Error -Newest 20
WhoCrashed: Analiza automaticamente los archivos de volcado en C:\Windows\Minidump y senala el driver o modulo responsable de un BSOD. Gratuito para uso personal.
BlueScreenView (NirSoft): Muestra el driver causante en lenguaje simple sobre los archivos minidump. Alternativa ligera sin instalacion.
Como Usar MemTest86

MemTest86 es el test de RAM mas confiable: arranca desde un USB sin cargar Windows y prueba cada celda de memoria. Es lento a proposito — una pasada completa puede tardar 1-2 horas.

PasoAccion
1Descarga la imagen ISO gratuita de MemTest86 del sitio oficial (memtest86.com) — la version Free es suficiente.
2Crea el USB booteable con Rufus: conecta un USB (minimo 2GB), selecciona la ISO y elige modo "MBR" o "UEFI" segun el firmware de tu PC.
3Reinicia, entra al menu de arranque (F12, F11 o Esc segun la placa) y arranca desde el USB.
4Configuracion recomendada: deja el test en "Auto" y deja pasar al menos 4 pasadas (varias horas). Cuantas mas pasadas, mas confiable el resultado.
5Lee el resultado en pantalla: si aparece "Errors: 0", la RAM esta sana. Cualquier error aparece en rojo con la direccion de memoria donde fallo.
6Si hay errores, prueba cada modulo individualmente en distintos slots para aislar la memoria o el slot defectuoso.
Alternativa rapida en Windows: ejecuta mdsched.exe (Diagnostico de memoria de Windows) y elige reiniciar ahora. Es menos exhaustivo que MemTest86 pero detecta fallas graves rapidamente y no requiere USB.
Importante: la RAM con errores causa BSOD aleatorios, corrupcion de archivos y cuelgues sin motivo aparente. Si MemTest86 marca errores, reemplaza el modulo — no hay software que "repare" memoria fisicamente defectuosa.
Metodologia de Pruebas de Estabilidad (Stress Tests)

El stress test verifica que el sistema sea estable bajo carga maxima. Cada componente tiene su prueba especifica; el objetivo es detectar errores de calculo, calor y artefactos.

ComponentePruebaDuracion sugeridaQue vigilar
CPUPrime95 (Small FFTs) u OCCT CPU30-60 minErrores de calculo, throttling, temperatura >90°C
GPUFurMark u OCCT GPU15-30 minArtefactos visuales, temperatura >90°C, cuelgues
RAMMemTest86 (USB) u OCCT Memory4+ pasadas / 1-2 horasErrores de memoria en rojo
DiscoCrystalDiskMark o HD TuneVarias pasadasVelocidad fuera de spec, errores de lectura
PSUOCCT PSU Test (GPU + CPU juntos)15-30 minApagados, voltajes fuera de tolerancia
  • Errores WHEA: en el Visor de eventos (Registros de Windows → Sistema) el codigo 19 o 18 en el origen "WHEA-Logger" indica error de hardware — el 19 apunta a CPU/RAM, el 18 a PCIe (a menudo GPU o NVMe). Tras un BSOD, revisa este log antes de culpar a un driver.
  • Artefactos en GPU: triangulos, rayas o puntos de colores durante FurMark indican VRAM o nucleo grafico inestable (sobrecalentamiento, overclock extremo o falla fisica).
  • Orden tras overclock: primero MemTest86 (RAM estable), luego Prime95 30 min (CPU), despues FurMark (GPU) y por ultimo OCCT PSU test. Nunca saltees pasos: una inestabilidad de RAM invalida los demas tests.
Monitorea temperaturas SIEMPRE durante el stress: deja HWiNFO abierto en segundo plano con el registro activo y revisa que las temperaturas no superen los limites del fabricante. Un test de estres sobre un equipo con falla termica previa puede danar componentes.
Visor de Eventos en Profundidad

El Visor de Eventos registra todo lo que ocurre en Windows y es la primera fuente de verdad ante BSOD, reinicios o servicios que fallan. Abrelo con eventvwr.msc (Win+R o desde el menu inicio).

  • Logs a revisar: "Registros de Windows → Sistema" (errores de hardware, controladores y servicios) y "Registros de Windows → Aplicaciones" (errores de programas).
  • Event ID 41 (Kernel-Power): el equipo se apago sin un apagado limpio (corte de energia, PSU o crash de hardware). Muy comun tras un BSOD o un apagon.
  • Event ID 1001 (BugCheck): se produjo un BSOD. Filtra este ID para ver la frecuencia exacta de las pantallas azules.
  • Event ID 6008: apagado inesperado detectado en el ultimo arranque (suele acompanar al 41).
  • Event ID 7000/7001: un servicio no pudo iniciarse o depende de otro que fallo. Tipico de drivers rotos tras una actualizacion.
  • Filtros y vistas personalizadas: crea una "Vista personalizada" por nivel de error critico y por intervalo para no leer el log completo cada vez.
  • Que ignorar: errores de discos externos desconectados bruscamente (Event ID 157 Kernel-Disk), cortes de WLAN intermitentes y errores de servicios de telemetria que no afectan el sistema.
powershell · consultar eventos por ID 
# Ultimos 50 errores del Sistema en las ultimas 24 horas
  > Get-WinEvent -FilterHashtable @{LogName='System'; Level=1,2; StartTime=(Get-Date).AddDays(-1)} -MaxEvents 50

  # Buscar BSOD (Event ID 1001) en el registro Sistema
  > Get-WinEvent -FilterHashtable @{LogName='System'; Id=1001} -MaxEvents 10

  # Errores WHEA de hardware (Provider WHEA-Logger)
  > Get-WinEvent -FilterHashtable @{LogName='System'; ProviderName='Microsoft-Windows-WHEA-Logger'} -MaxEvents 10
Practica: cuando diagnostiques un reinicio misterioso, filtra por Event ID 41 y 1001 en las ultimas 2 semanas y compara las horas con tu historial de BSOD. La correlacion de horas resuelve la mayoria de los casos.
Limpieza Completa de Drivers de GPU (DDU)

Display Driver Uninstaller (DDU) elimina por completo los drivers de la tarjeta grafica, incluidos registros, archivos sobrantes y servicios ocultos que el desinstalador normal deja atras.

  • Cuando usar DDU: cambiar de NVIDIA a AMD o viceversa, drivers corruptos o instalaciones fallidas, BSOD relacionados con display, o artefactos tras actualizar el driver.
  • Descarga previa: baja la ultima version de DDU (wagnardsoft.com) y los drivers nuevos de tu GPU (NVIDIA o AMD) ANTES de limpiar — despues de DDU el sistema queda sin driver de video.
PasoAccion
1Descarga DDU y los drivers nuevos. Extrae DDU a una carpeta (no hace falta instalar).
2Arranca en modo seguro: Shift + Reiniciar → Solucionar problemas → Opciones avanzadas → Modo seguro.
3Ejecuta Display Driver Uninstaller.exe y selecciona "Limpiar y reiniciar" (elige el fabricante correcto: NVIDIA, AMD o Intel).
4Windows se reinicia solo y arranca con el driver generico de Microsoft.
5Instala el driver nuevo descargado (ejecuta el instalador como administrador) y reinicia una vez mas.
6Verifica con GPU-Z que el driver, la frecuencia y la resolucion correctas esten activas.
Advertencia: DDU borra TODOS los drivers de GPU del fabricante seleccionado, incluidos los de otros adaptadores. No lo uses "por curiosidad" sobre un sistema estable — si tu PC funciona bien, no necesitas DDU.
