Ruidos extranos

Mantenimiento · Mantenimiento Correctivo

Inicio/Mantenimiento/Mantenimiento Correctivo/Ruidos extranos

Un ruido nuevo o inusual es una de las primeras senales de que algo falla. Aprender a identificar el tipo de ruido permite actuar antes de que el dano sea irreparable.

Regla general: si escuchas un ruido que no existia antes, apaga la PC y verifica visualmente antes de seguir usando el equipo. Un ruido pode ser el preludio de un fallo catastrofico.
Tipo de ruidoProbable origenQue hacer
Clics repetitivos (clic-clic-clic)Disco duro mecanico con sectores danadosApagar YA. Respaldar datos urgentemente con CrystalDiskInfo. El disco esta por fallar.
Zumbido o chillido electronico (coil whine)Vibracion de bobinas en la GPU o la PSU bajo cargaNo es peligroso pero es molesto. Si es GPU: limitar FPS ayuda. Si es PSU: puede indicar calidad deficiente.
Chirrido o rasquido mecanicoVentilador con ruleta desgastada o cable rozando aspasAbrir el gabinete, identificar el fan, comprobar que no toca cables. Si chirria: reemplazar el ventilador.
Zumbido grave y constanteVentilador de CPU o GPU girando a maxima velocidadRevisar temperaturas con HWMonitor. Si estan altas: limpiar polvo, renovar pasta termica.
Golpes o traqueteo intermitenteDisco duro con platos danados o ventilador sueltoSi es disco: respaldar y reemplazar. Si es fan: apretar tornillos o reemplazar.
Siseo constante (aire)Filtracion de aire por espacios estrechos o PSU de baja calidadNormal si es bajo. Si es excesivo: revisar sellos del gabinete y calidad de la PSU.
Pitido continuo (beep)POST fallido (ver Beep Codes)Seguir la tabla de beep codes de tu BIOS para identificar el componente.
Technica de aislamiento: abre el gabinete y escucha de cerca. Con el equipo encendido, acerca el oido (sin tocar nada) para identificar que componente es. Tambien puedes pausar temporalmente cada ventilador sujetando la aspa con el dedo (con cuidado).
Prioridad critica: los clics de un disco duro son la senal mas urgente. Cada minuto que el disco sigue funcionando es un minuto menos para recuperar tus datos. Usa CrystalDiskInfo para verificar la salud SMART y Recuperacion de Datos para actuar.
