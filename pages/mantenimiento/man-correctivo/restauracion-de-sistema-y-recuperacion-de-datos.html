Restauracion de Sistema y Recuperacion de Datos

Mantenimiento · Mantenimiento Correctivo — Leccion 8 de 9

Inicio/Mantenimiento/Mantenimiento Correctivo/Restauracion de Sistema y Recuperacion de Datos

Cuando Windows falla tras una actualizacion o cambio de configuracion, no hace falta reinstalar todo. Estos son los niveles de recuperacion de menor a mayor impacto:

MetodoQue haceCuando usarlo
Punto de restauracionRevierte archivos de sistema y configuracion a una fecha anteriorFallo tras instalar driver/programa; no toca tus documentos
Desinstalar ultima actualizacionElimina un KB especifico de Windows UpdateProblemas tras una actualizacion reciente
Reparar inicio (Startup Repair)Reconstruye el arranque y el bootloaderWindows no arranca, pantalla negra o "bootmgr missing"
sfc /scannow + DISMRevisa y repara archivos de sistema corruptosErrores de archivos, BSOD recurrentes
Restablecer este PC (conservar archivos)Reinstala Windows conservando documentos y apps de la StoreFallo grave de sistema, ultimo intento antes del formateo
Reinstalacion limpiaFormatea y reinstala desde ceroInfeccion grave, disco corrupto o Windows inutilizable
Antes de reinstalar o formatear, intenta rescatar datos: bootea con un USB de Linux (Live USB) o conecta el disco a otra PC para copiar archivos. Si el disco no aparece en Windows, prueba con chkdsk X: /f o herramientas como Recuva / PhotoRec para archivos borrados.
cmd · recuperacion (ejecutar como Administrador) 
# Reparar archivos de sistema
  > sfc /scannow
  > DISM /Online /Cleanup-Image /RestoreHealth

  # Reparar el arranque
  > bootrec /fixmbr # y luego
  > bootrec /fixboot # y luego
  > bootrec /rebuildbcd
