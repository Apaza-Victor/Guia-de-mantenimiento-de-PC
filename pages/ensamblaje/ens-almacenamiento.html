Almacenamiento

// Donde viven tus datos y tu sistema operativo

La mejor combinacion: un SSD NVMe para el sistema operativo y programas, y un HDD grande o SSD de capacidad para datos, juegos y copias de seguridad.

Claves de los M.2

  • Keys: la muesca de la tarjeta. Key M = PCIe/NVMe (y SATA en algunos), Key B = SATA (o PCIe x2). Los slots de placa moderna aceptan M.2 Key M (y algunos duales B+M).
  • Revision: el slot puede ser PCIe 3.0, 4.0 o 5.0. Un NVMe 4.0 en slot 3.0 funciona, pero a la velocidad del slot.
  • Disipador: los NVMe 4.0/5.0 rapidos generan calor; muchas placas traen un heatsink sobre el slot M.2.

NVMe es el protocolo sobre PCIe; el formato M.2 es solo fisico. Un M.2 puede ser SATA (mas lento) o NVMe (mas rapido). Revisa que tu placa lo soporte antes de comprar.

  • TBW (Terabytes Written): cuantos TB puedes escribir antes de que las celdas se degraden. Para uso normal, 300-600 TBW duran anos.
  • DRAM vs sin DRAM: un SSD con cache DRAM mantiene mejores velocidades sostenidas. Los sin DRAM (usualmente los economicos) bajan la velocidad al escribir archivos grandes.
  • S.M.A.R.T.: todos los discos reportan datos de salud (temperatura, errores, horas). Se revisa con herramientas como CrystalDiskInfo.
HDD: RPM, cache y CMR vs SMR
  • 5400 RPM: mas silencioso y fresco, para almacenamiento masivo.
  • 7200 RPM: mas rapido, para discos de datos/uso frecuente.
  • Cache: 32-256 MB; ayuda con operaciones repetidas.
  • CMR: las pistas no se superponen; escritura estable. Ideal para RAID y NAS.
  • SMR: mas capacidad por plato pero escrituras sostenidas lentas. NO recomendado para RAID.
Los HDD de escritorio y los de NAS parecen iguales, pero los NAS estan disenados para vibracion y uso 24/7 con funcionalidades especificas. Para un NAS o servidor, compra discos NAS/Enterprise.

  • Hardware RAID: controladora propia (placa o tarjeta). Mas confiable y sin carga al CPU.
  • Software RAID / Storage Spaces / mdadm: usa el SO; facil de configurar, sin hardware extra.
  • RAID no es una copia de seguridad: no protege de borrados, virus ni incendios. Siempre respalda aparte.
Como elegir para tu caso
  • PC de oficina / hogar: 1 SSD NVMe de 512 GB - 1 TB para todo.
  • Gaming: NVMe 1 TB para SO + juegos activos, HDD o SSD 2 TB para la biblioteca.
  • Creator / video: NVMe 4.0 rapido para el proyecto y discos grandes para material.
  • NAS / servidor: discos NAS/Enterprise con RAID 1 o 5 + respaldo externo.
  • Laptop: prioriza NVMe de bajo consumo (los QLC con cache funcionan bien).
Para particionar y elegir formato de archivos al instalar el sistema, consulta Sistema Operativo e Instalacion y Almacenamiento.
