Dispositivos Especiales

All-in-One · Tabletas · Mac · Mini-PC · Chromebooks

Inicio/Ensamblaje/Atajos BIOS/Dispositivos Especiales
DispositivoAcceso a BIOS/UEFIBoot / Recovery
Apple Mac (Intel)Sin BIOS; mantén Option (Alt) al encenderOption = Boot Picker · Cmd+R = Recovery · Cmd+Option+P+R = reset NVRAM
Apple Mac (Apple Silicon M1-M4)Sin BIOS; mantén el boton de encendidoMantener Power = Opciones de inicio / Recovery
All-in-One HPF10 (Esc luego F10)F9 / Esc
All-in-One DellF2F12
All-in-One LenovoF1 o F2F12
iMac (2019 y anteriores)Option al encenderCmd+R = Recovery · Cmd+Option+R = Internet Recovery
Intel NUC / Mini-PCF2F10
Microsoft Surface Go / ProMantener subir volumen + PowerBajar volumen + Power = UEFI avanzado
ChromebookCtrl+L en pantalla de bloqueo (modo developer)Esc + Refresh + Power = recovery / limpieza
Tablet Android (root/BIOS)Depende del fabricante (Vol- + Power)Vol- + Power = Recovery / Fastboot
Mini PC Beelink / MinisforumDel o F2F7 / F11
Mini PC ASUS PN / ExpertCenterF2 (a veces Del)Esc / F8
Mini PC MSI CubiDelF11
Lenovo ThinkCentre TinyF1F12
Dell OptiPlex MicroF2F12
HP Elite / Pro MiniF10 (Esc luego F10)F9
Zotac ZBOXDelF11
Steam DeckMantener Vol- + Power → menú de inicioSeleccionar "Setup Utility" en el menú
ASUS ROG Ally / Ally XMantener Vol- + PowerMismo método (menú UEFI)
Lenovo Legion GoMantener Vol- + PowerMismo método (menú UEFI)
Servidor Dell PowerEdgeF2 (System Setup)F11 (Boot Manager)
Servidor HP ProLiantF9 (ROM-Based Setup)F11 / F10 (Provisioning)
Servidor / placa SupermicroDelF11
Raspberry Pi 4/5 (SBC)Sin BIOS; la config esta en config.txt o rpi-eepromSin boot menu (EEPROM / config)
Nota: Los equipos Apple, los dispositivos moviles y los SBC no usan BIOS/UEFI tradicional. En Mac se accede al firmware manteniendo teclas al encender; en tablets y consolas portatiles se usa la combinacion de botones fisicos; en Raspberry Pi la configuracion se hace por archivos (config.txt / rpi-eeprom).
