Configuraciones Utiles del BIOS/UEFI

Prioridad de arranque ┬À UEFI/Legacy ┬À XMP/EXPO ┬À TPM ┬À Virtualizacion ┬À Fast Boot

Inicio/Ensamblaje/ens-atajos-bios/Configuraciones Utiles del BIOS/UEFI

Estas son las opciones mas usadas y donde encontrarlas segun el fabricante de tu placa o equipo.

ConfiguracionRuta tipicaPara que sirve
Prioridad de arranque (Boot Order)Boot ÔåÆ Boot Priority / Boot Option #1Elegir disco, USB o DVD de arranque. Mueve la unidad con +/ÔêÆ o arrastra.
Modo UEFI vs Legacy (CSM)Boot ÔåÆ Boot Mode / CSMUEFI (GPT, recomendado, soporta Secure Boot) vs Legacy (MBR). En equipos de marca: "Legacy Support" activado/desactivado.
Secure BootBoot / Security ÔåÆ Secure BootFiltrar SO sin firma (ver seccion anterior).
TPM 2.0 (fTPM / PTT)Security ÔåÆ Trusted Computing / AMD fTPM / Intel PTTObligatorio para Windows 11, BitLocker, Windows Hello.
VirtualizacionAdvanced ÔåÆ CPU Config ÔåÆ SVM (AMD) o Intel VT-x (Intel)Necesaria para maquinas virtuales (VirtualBox, VMware, WSL2, Android Studio). Tambien existe VT-d / AMD-Vi para passthrough.
XMP / EXPO (perfil de RAM)OC / Ai Tweaker ÔåÆ XMP (Intel) o EXPO (AMD)Activar la velocidad anunciada de la RAM (DDR4 3200+, DDR5). Evita andar a velocidad base JEDEC.
Fast BootBoot ÔåÆ Fast BootAcelera el arranque saltando parte del POST. Si se activa, suele exigir teclas mas tempranas para entrar a BIOS.
Graficos primariosAdvanced ÔåÆ Init Display First / Primary Graphics AdapterElegir si la salida de video inicial es la GPU dedicada (PEG) o la integrada (IGD).
Wake on LAN / encendido por ACAdvanced ÔåÆ Power / APM ConfigurationEncender el PC por red o que arranque al conectar corriente (Restore on AC Power Loss).
Control de ventiladoresHardware Monitor / Q-Fan (ASUS) / Smart Fan (MSI)Ajustar curvas de RPM de fans CPU/caja para ruido y temperatura.
Tip: En placas ASUS presiona F7 dentro de la BIOS para cambiar del modo "Easy Mode" al "Advanced Mode" y ver todas las opciones. En Gigabyte es F2. Muchas opciones (como TPM o Virtualizacion) solo aparecen en modo avanzado.
