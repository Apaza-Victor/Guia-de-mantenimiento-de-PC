Tip universal Si no sabes la tecla exacta, presiona repetidamente ESC, DEL, F1, F2, F10, F11 y F12 (en ese orden) justo despues de presionar el boton de encendido.

Entrar a BIOS desde Windows (sin reiniciar manualmente)

cmd / powershell — entrar a BIOS
# Comando directo (como administrador)
  > shutdown /r /fw /t 0
  # Reinicia directamente a la configuracion de firmware UEFI
  # Solo funciona en equipos con UEFI (no BIOS Legacy antigua)

Entrar a BIOS desde Linux

bash — systemctl reboot-to-firmware
# En distribuciones con systemd (Ubuntu, Fedora, Debian, Arch...)
  $ systemctl reboot --firmware-setup
