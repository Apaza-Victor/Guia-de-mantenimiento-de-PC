Entrar a BIOS desde Windows (sin reiniciar manualmente)

cmd / powershell — entrar a BIOS
# Comando directo (como administrador)
  > shutdown /r /fw /t 0
  # Reinicia directamente a la configuracion de firmware UEFI
  # Solo funciona en equipos con UEFI (no BIOS Legacy antigua)

Entrar a BIOS desde Linux

bash — systemctl reboot-to-firmware
# En distribuciones con systemd (Ubuntu, Fedora, Debian, Arch...)
  $ systemctl reboot --firmware-setup
Secure Boot — Desactivar / Activar
Pasos por fabricante · Windows 11 · TPM · por que y cuando desactivarlo
▼

Secure Boot es una caracteristica del UEFI que solo permite arrancar sistemas operativos con firma digital valida (Windows 8/10/11, la mayoria de distros Linux modernas). Impide que malware o un SO sin firmar se cargue antes que el sistema.

¿Cuando desactivarlo? Necesitas desactivar Secure Boot para: instalar Windows 7 o versiones anteriores, algunos Linux antiguos o con drivers sin firmar, usar ciertos discos/adaptadores de arranque, o instalar SO alternativos. Es una medida de seguridad: desactivado NO es lo recomendado salvo que lo necesites, y conviene reactivarlo al terminar.
FabricanteRuta en el BIOS/UEFIValor que cambia
ASUSBoot → Secure Boot → OS Type"Other OS" desactiva · "Windows UEFI mode" lo activa
MSISettings → Security → Secure BootDisabled / Enabled
GigabyteBoot → Secure BootEnabled / Disabled (a veces "Windows 10" vs "Other OS")
ASRockSecurity → Secure BootDisabled / Enabled
DellSecure Boot → Secure Boot EnableDisabled / Enabled
HPSecurity → Secure Boot Configuration → Secure BootDisable / Enable (o activar "Legacy Support" primero)
LenovoSecurity → Secure BootDisabled / Enabled
AcerSecurity → Set Supervisor Password (primero) → Secure BootDisabled (pide contraseña de supervisor para guardar)
En equipos de marca (Dell/HP/Lenovo) antes de desactivar Secure Boot muchas veces hay que poner una contraseña de BIOS (BIOS password) o activar la opcion "Legacy Support" / "Legacy ROM". Sin eso la opcion aparece atenuada (gris) y no se puede cambiar. Guarda esa contraseña: la pediran para modificar cualquier ajuste de seguridad.

Desactivar Secure Boot desde Windows (sin teclas al encender)

cmd — reiniciar directo a la configuracion UEFI
# Reinicia directo a la pantalla de UEFI Firmware Settings
  > shutdown /r /fw /t 0
  # Alternativa: Configuracion > Sistema > Recuperacion > Inicio avanzado
  # > Reiniciar ahora > Solucionar problemas > Opciones avanzadas > Configuracion de firmware UEFI
Windows 11 y TPM: Windows 11 exige TPM 2.0 y, por defecto, Secure Boot activado. Si desactivas Secure Boot no se debe instalar Windows 11 de forma normal (usa Rufus con la opcion "Extended Windows 11 Installation" si lo necesitas). El TPM suele llamarse TPM 2.0 (Intel) o fTPM / AMD CPU fTPM (AMD) y se activa/desactiva en Security → Trusted Computing / AMD fTPM.

Reactivar Secure Boot despues

Vuelve a la misma ruta y deja la opcion en Enabled / "Windows UEFI mode". Si el sistema ya tenia un SO instalado y Secure Boot estaba activado antes, Windows y Linux con secure boot habilitado arrancaran sin problemas. Solo si se borraron las claves (Reset Keys / Restore Factory Keys) habria que reinstalar claves de fabrica: opcion Restore Factory Keys dentro del mismo menu Secure Boot.

No Puedes Entrar a la BIOS? — Soluciones
Fast Boot · teclado USB · pantalla negra · arranque tan rapido que se salta el POST
▼
ProblemaSolucion
El equipo arranca tan rapido que no alcanzo a presionar la teclaActiva "Boot Delay"/"F12 Delay" en la BIOS (si entraste antes) o usa el reinicio desde Windows/Linux (comandos de arriba). Desactiva Fast Boot.
El teclado USB no responde durante el POSTEn BIOS: habilita "USB Legacy Support" y desactiva "XHCI Hand-off". Prueba otro puerto USB 2.0 (negro) y un teclado PS/2 si lo tienes.
Pantalla negra al entrar a la BIOS (monitor en la GPU)Conecta el cable de video a un puerto de la motherboard (video integrado) o espera a que cargue el driver. Si no, la salida inicial puede estar en IGD (ver tabla anterior).
Aparece un logo y la tecla no hace nadaPresiona la tecla en intervalos rapidos apenas enciende, no mantenerla. En HP/Dell prueba Esc o Enter primero (luego F10/F2).
BIOS protegida con contraseñaIntenta el metodo de reset CMOS de abajo. Si no funciona, contacta al fabricante (en laptops suele requerir servicio tecnico).
Restablecer la BIOS (Reset CMOS)
Bateria · jumper · boton trasero · restaurar valores de fabrica
▼

Restablecer la BIOS vuelve a los valores de fabrica y borra configuraciones que impiden arrancar (perfil de RAM inestable, overclock fallido, contraseña de BIOS en muchos casos). Detalle completo en Conceptos Clave → CMOS / Reset CMOS.

Importante: Desconecta el equipo de la corriente (y quita la bateria si es laptop) antes de tocar el jumper o la pila. Trabaja con una pulsera antiestatica si tienes una.

Metodos de reset

MetodoPasosIdeal para
Desde la propia BIOSExit → Load Optimized / Load Setup Defaults → Save & ExitLo mas facil y seguro; la BIOS todavia arranca.
Jumper CLR_CMOSCon el PC apagado y sin corriente, puentea los 2 pines 5-10 segundos y devuelve el jumper a su posicion.Placas de escritorio. No requiere abrir mas.
Pila (bateria CR2032)Quita la pila de la motherboard 5-10 minutos y vuelve a colocarla.Cualquier placa; quita tambien la contrasena en muchos casos.
Boton trasero (Clear CMOS)Algunas placas gaming traen un boton en el panel I/O. Pulsa 5-10 segundos con el PC apagado.Placas ASUS ROG / MSI / Gigabyte gaming y consolas.
Tras el reset: tendras que volver a configurar fecha/hora, perfil de RAM (XMP/EXPO), prioridad de arranque y las opciones de seguridad (Secure Boot, TPM) porque todo vuelve a valores por defecto.
