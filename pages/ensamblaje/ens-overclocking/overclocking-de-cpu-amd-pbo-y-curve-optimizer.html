Overclocking de CPU — AMD (PBO y Curve Optimizer)

Boost automatico seguro + undervolting fino

Inicio/Ensamblaje/Overclocking y Undervolting Practico/Overclocking de CPU — AMD (PBO y Curve Optimizer)
Opcion BIOSQue haceNivel de riesgo
PBO (Enabled/Advanced)Permite que el CPU use mas potencia y suba mas el boost hasta el limite termicoBajo (se autorregula)
PBO Limits (PPT/TDC/EDC)Sube los limites de energia y corriente (ej. Motherboard preset)Bajo-medio
Curve OptimizerAplica voltaje negativo por nucleo (-5 a -30) para bajar temperatura y subir boostMedio (hay que probar estabilidad)
Manual multiplierFija frecuencia fija ignorando boostAlto (pierde single-core)

El Curve Optimizer con offset negativo es el metodo estrella en Ryzen 5000/7000: bajas temperatura, el CPU mantiene mas tiempo su boost maximo y el resultado es "overclock gratis". Empieza con -10 all-core y baja de a -5 probando con OCCT.
