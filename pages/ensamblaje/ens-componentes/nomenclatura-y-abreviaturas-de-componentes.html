Nomenclatura y Abreviaturas de Componentes

Ensamblaje · Componentes de Hardware — Leccion 17 de 19

Inicio/Ensamblaje/Componentes de Hardware/Nomenclatura y Abreviaturas de Componentes

Conocer la terminologia tecnica te ayudara a comunicarte con otros tecnicos y a entender manuales, especificaciones y foros de la comunidad.

Sigla / Termino Significado Completo Descripcion
ATXAdvanced Technology ExtendedEstandar de factor de forma para placas base (305x244mm). Define dimensiones, posiciones de tornillos y distribucion de conectores.
mATXMicro ATXVersion reducida de ATX (244x244mm). Menos slots de expansion pero compatible con gabinetes ATX.
ITX / Mini-ITXInformation Technology eXtendedFactor de forma compacto (170x170mm). Solo 1 slot PCIe y 2 slots RAM. Para builds pequeños.
SFXSmall Form FactorEstandar de PSU compacta para gabinetes SFF. Misma potencia que ATX pero en tamano reducido.
EPSExtended Power SupplyConector de alimentacion de CPU de 8 pines (4+4). Provee +12V directo al VRM del procesador.
PCIePeripheral Component Interconnect ExpressBus de datos de alta velocidad para GPUs, SSD NVMe y tarjetas de expansion. Versiones: 3.0, 4.0, 5.0.
DDR4 / DDR5Double Data Rate 4/5Generaciones de memoria RAM. DDR4: hasta 3200-4600 MHz. DDR5: desde 4800 MHz. No son intercambiables.
NVMeNon-Volatile Memory ExpressProtocolo de comunicacion para SSDs via PCIe. Mucho mas rapido que SATA. Latencia extremadamente baja.
AHCIAdvanced Host Controller InterfaceProtocolo de controlador de almacenamiento para SSD SATA y HDD. Menor rendimiento que NVMe.
RAIDRedundant Array of Independent DisksTecnologia que combina multiples discos para mayor velocidad (RAID 0), redundancia (RAID 1) o ambos (RAID 5/10).
VRMVoltage Regulator ModuleCircuito en la placa base que regula el voltaje que llega al CPU. Mas fases = mejor estabilidad.
TDPThermal Design PowerCalor maximo que disipa el cooler. En AMD/Intel indica la potencia termica tipica del procesador.
IHSIntegrated Heat SpreaderTapa metalica sobre el die del CPU que distribuye el calor hacia el cooler.
POSTPower-On Self TestVerificacion inicial de hardware al encender el PC. Error aqui = pitidos o LEDs de debug.
XMP / EXPOExtreme Memory Profile / Extended Profiles for OverclockingPerfiles en la BIOS para ejecutar la RAM a su velocidad anunciada. Intel usa XMP, AMD usa EXPO.
BIOS / UEFIBasic I/O System / Unified Extensible Firmware InterfaceFirmware que inicializa el hardware antes de cargar el sistema operativo. UEFI es la version moderna.
GPT / MBRGUID Partition Table / Master Boot RecordEsquemas de particionado de discos. GPT es moderno (>2TB, UEFI). MBR es legado (max 2TB, BIOS).
