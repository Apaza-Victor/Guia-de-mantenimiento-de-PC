Guia USB Booteable

// Crear USBs de arranque con Rufus y Ventoy

Metodo 1: Rufus (Windows)

Rufus es la herramienta mas popular y confiable para crear USBs booteables. Soporta BIOS legacy y UEFI, esquemas MBR y GPT, y puede descargar ISOs de Windows directamente desde Microsoft.

PASO 1
Descargar Rufus desde rufus.ie
Version portable — no requiere instalacion. Ejecutar como administrador.
PASO 2
Seleccionar dispositivo e imagen ISO
Device: tu USB. Boot selection: SELECT y elegir el archivo ISO descargado.
PASO 3
Configurar esquema de particion
GPT si tu PC usa UEFI (la mayoria desde 2012). MBR si usa BIOS Legacy antiguo.
PASO 4
Sistema de archivos
NTFS para Windows 11 (soporta archivos grandes). FAT32 solo si tu placa es muy antigua.
PASO 5
Iniciar y esperar
Click START, confirmar el borrado del USB. Espera 10-15 minutos hasta ver READY.
Extended Windows 11:Rufus permite instalar Windows 11 en PCs sin TPM 2.0 ni Secure Boot. Al seleccionar la ISO, Rufus ofrece la opcion "Extended Windows 11 Installation".
Metodo 2: Ventoy (Multiples ISOs en un solo USB)
Por que usar Ventoy?Se instala UNA sola vez en el USB y luego solo copias archivos .iso directamente como si fuera una carpeta. Al arrancar, Ventoy muestra un menu para elegir cual ISO bootear. Ideal para tecnicos que cargan Windows, varios Linux, Hiren's BootCD y herramientas de diagnostico en el mismo pendrive.
PASO 1
Descargar Ventoy desde ventoy.net
Disponible para Windows y Linux. Extraer el zip descargado.
PASO 2
Instalar Ventoy en el USB
Windows: ejecutar Ventoy2Disk.exe como administrador, seleccionar USB, click Install. Linux: sudo sh Ventoy2Disk.sh -i /dev/sdX
PASO 3
Copiar archivos ISO al USB
Simplemente copia y pega los archivos .iso al USB como archivos normales. No necesitas formatear de nuevo.
PASO 4
Arrancar desde el USB
Reiniciar y seleccionar el USB como dispositivo de arranque. Ventoy mostrara un menu con todas las ISOs disponibles.
KIT USB recomendado para tecnico:Usa Ventoy en una memoria de 32-64 GB y copia las ISOs de Hiren's BootCD PE, MemTest86, GParted Live, Clonezilla y el instalador de Windows 10/11. Un solo USB resuelve el 95% de emergencias.
Metodo 3: Balena Etcher (Windows / macOS / Linux)

Balena Etcher es la herramienta multiplataforma mas sencilla para grabar ISOs. Ideal para Linux, Raspberry Pi (Raspberry Pi OS) y sistemas tipo "live". No es multiboot: un USB = una imagen.

PASO 1
Descargar desde etcher.balena.io
Elegir el instalador segun tu sistema (Windows, macOS o Linux). Tiene version portable que no requiere instalacion.
PASO 2
Seleccionar la imagen
Click "Flash from file" y elegir la ISO descargada. Etcher tambien graba imagenes .img y .gz.
PASO 3
Seleccionar el USB destino
Elegir "Select target" y marcar el pendrive correcto. Etcher evita por defecto elegir el disco del sistema.
PASO 4
Flash y verificacion
Click "Flash!". Etcher escribe la imagen y luego la verifica automaticamente para detectar errores de grabado.
Cuando usar Etcher:es la opcion mas facil para grabar distribuciones Linux o sistemas embebidos. Para Windows y USBs multiboot, prefiere Rufus o Ventoy.
Metodo 4: Media Creation Tool (Windows 10/11 oficial)

Herramienta oficial de Microsoft para crear el USB de instalacion de Windows o descargar la ISO original. Garantiza un instalador 100% limpio y actualizado, sin recurrir a terceros.

PASO 1
Descargar desde microsoft.com
En la pagina oficial de descarga de Windows 11 (o Windows 10), seccion "Crear medios de instalacion de Windows". Ejecutar como administrador.
PASO 2
Aceptar licencia y elegir idioma
Aceptar los terminos. Desmarcar "Usar las opciones recomendadas" si quieres elegir otro idioma, edicion o arquitectura (x64).
PASO 3
Elegir "Unidad flash USB"
Seleccionar "Crear medios de instalacion" y despues "Unidad flash USB". Elegir el pendrive (minimo 8 GB).
PASO 4
Esperar la descarga
La herramienta descarga Windows e instala todo en el USB. Puede tardar 30-60 minutos segun la conexion.
Alternativa:en la misma pagina, la opcion "Descargar la imagen de disco ISO de Windows" te da la ISO oficial para usarla luego con Rufus o Ventoy (util si quieres varios instaladores en un USB multiboot).
Metodo 5: UNetbootin (Linux / Windows / macOS)

UNetbootin crea USBs booteables desde una ISO o descargando la distribucion Linux directamente desde la aplicacion. Multiplataforma y util cuando trabajas desde Linux y no tienes Rufus.

PASO 1
Descargar desde unetbootin.github.io
Elegir la version para tu sistema. En Linux tambien se instala con sudo apt install unetbootin.
PASO 2
Elegir "Imagen de disco" y el USB
Marcar "Imagen de disco" y seleccionar la ISO. Abajo, elegir el USB como "Tipo" y "Unidad" correctas.
PASO 3
Instalar / extraer
Click OK. UNetbootin copia los archivos de arranque y la ISO. Cuando termine, retira el USB de forma segura.
Nota:en algunas distros nuevas UNetbootin puede fallar con UEFI. Si el USB no arranca, prueba con Rufus (en Windows), Etcher o Ventoy.
Metodo 6: dd — crear USB desde Linux / macOS

dd escribe la ISO byte a byte directo al USB usando solo la terminal. No requiere instalar nada, pero es PELIGROSO: si eliges el disco equivocado lo borras sin confirmacion.

PASO 1
Identificar el USB
Ejecuta lsblk en Linux o diskutil list en macOS. Anota el dispositivo (ej. /dev/sdb) y su tamano para no confundirlo.
PASO 2
Desmontar el USB
Linux: sudo umount /dev/sdb1. macOS: diskutil unmountDisk /dev/disk2.
PASO 3
Escribir la imagen
Linux: sudo dd if=imagen.iso of=/dev/sdb bs=4M status=progress oflag=sync. macOS: usa bs=1m y /dev/rdisk2 (mas rapido).
PASO 4
Sincronizar y retirar
Ejecuta sync y espera a que termine de escribir antes de sacar el USB.
Cuidado extremo:dd no pide confirmacion y sobrescribe el destino completo. Verifica dos veces que /dev/sdX sea realmente el USB. Un solo error borra el disco del sistema.
Metodo 7: YUMI — multiboot con menu (Windows / Linux)

YUMI (Your Universal Multiboot Installer) crea un USB con menu propio al que vas agregando ISOs una por una. Es el clasico multiboot de Pendrive Linux y sigue activo con versiones para Windows y Linux (YUMI Py).

PASO 1
Descargar YUMI desde pendrivelinux.com
La version recomendada es YUMI Py (multiplataforma, formato exFAT). Ejecutar como administrador.
PASO 2
Crear el USB multiboot
Seleccionar el USB, marcar la opcion de formateo y click "Create". YUMI prepara el pendrive con su propio bootloader.
PASO 3
Agregar ISOs una por una
Elegir la distribucion o "Other ISOs" y seleccionar el archivo .iso. Se agrega al menu sin borrar lo ya cargado.
PASO 4
Arrancar y elegir en el menu
Al bootear, YUMI muestra su menu con todas las ISOs. Soporta persistencia para distros compatibles (Ubuntu, Debian, Fedora).
YUMI vs Ventoy:Ventoy es mas simple (solo copias ISOs como archivos). YUMI necesita registrar cada ISO con la app pero ofrece persistencia y opciones por distribucion.
Medicat USB — kit todo-en-uno de rescate (basado en Ventoy)
Que es Medicat?Es un USB multiboot completo (usa Ventoy como base) que empaqueta decenas de herramientas de diagnostico y recuperacion en un solo pendrive: WinPE, antivirus, recuperacion de contrasenas, clonado de discos, testeo de RAM/GPU, gestores de particiones y mas. Es la "navaja suiza" del tecnico.
PASO 1
Descargar desde medicatusb.com
Requisito: un USB de al menos 32 GB (recomendado USB 3.0 o superior). Descarga la version Full y verifica los checksums publicados.
PASO 2
Instalar Ventoy en el USB
Medicat funciona sobre Ventoy. Ejecuta Ventoy2Disk.exe, selecciona el USB y click Install.
PASO 3
Formatear en NTFS
Despues de instalar Ventoy, formatea el USB en NTFS para soportar los archivos grandes de Medicat.
PASO 4
Extraer Medicat al USB
Descomprime el archivo .7z (con 7-Zip) directamente en la raiz del USB. Alternativa: usa el instalador .bat (Windows) o .sh (Linux) incluido.
PASO 5
Arrancar y elegir herramienta
Bootea desde el USB y veras el menu de Medicat con todas las herramientas organizadas por categoria.
Consejo:desactiva temporalmente el antivirus durante la instalacion: algunos paquetes de Medicat incluyen herramientas de recuperacion de contrasenas que los antivirus marcan como riesgo (falsos positivos conocidos).

Que es MBR vs GPT — Tablas de particiones explicadas

La tabla de particiones es el "mapa" grabado al inicio del disco que le dice al firmware y al sistema operativo donde empieza y termina cada particion (C:, D:, /home...). Hay dos estandares: MBR (antiguo) y GPT (moderno). Tu PC arranca solo si la tabla del disco coincide con el modo del firmware: BIOS legacy lee MBR, UEFI lee GPT.

Disco con tabla MBR: sector de arranque + max 4 primariasgirar / zoom
Disco con tabla GPT: MBR protector + header + ESP + mas particiones + respaldogirar / zoom

Colores en los visores — MBR: dorado = sector de arranque; luego maximo 4 particiones (azul, verde, naranja, morado). GPT: rojo = MBR protector, dorado = header GPT, verde = particion EFI (ESP), mas particiones de colores y otra copia dorada al final (respaldo de la tabla).

Tipos de Sistemas Operativos

El sistema operativo (SO) es el software base que gestiona el hardware, los archivos, la red y la seguridad, y permite ejecutar programas. Antes de instalar conviene conocer las familias que existen y para que sirve cada una.

  • Windows: el mas usado en hogares y empresas. De 64 bits; requisitos estrictos en Windows 11 (TPM 2.0, Secure Boot). Ideal como primera opcion por compatibilidad.
  • Linux: existen cientos de distribuciones. Para empezar: Ubuntu (facil), Linux Mint (ligera y amigable) o Debian (estable). Se instala gratis y revive equipos viejos.
  • macOS: exclusivo de Apple, fluido y seguro, pero no se instala en PC convencionales (solo Macs).
  • ChromeOS: sistema de los Chromebooks, basado en el navegador Chrome y el nucleo Linux; ligero y orientado a la nube.
  • Servidor: igual que el escritorio pero optimizado para servicio continuo, sin interfaz grafica opcional y con roles como DNS, web o virtualizacion.
  • Live / Rescate: no se instalan; arrancan desde un USB para reparar el sistema actual o recuperar datos. Muy utiles para mantenimiento.
Tip: un mismo equipo puede tener varios sistemas con dual boot (mas abajo) o maquinas virtuales. Para aprender Linux sin riesgo, instala Windows y una distro en VirtualBox o usa un Live USB primero.
Requisitos de Windows 11 y Verificacion TPM

Windows 11 impone requisitos de hardware mas estrictos que Windows 10, centrados en seguridad (TPM 2.0 y Secure Boot). Revisalos antes de planificar una instalacion.

RequisitoValor minimo
ProcesadorCPU compatible de 64 bits, 1 GHz o mas, 2 nucleos como minimo
RAM4 GB
Almacenamiento64 GB
FirmwareUEFI con Secure Boot
SeguridadTPM 2.0
GraficosGPU compatible con DirectX 12 y driver WDDM 2.0
Pantalla9 pulgadas, resolucion HD (720p)
  • Verificar TPM: Pulsa Win+R y ejecuta tpm.msc. Debe indicar "El TPM esta listo para su uso" y version 2.0.
  • PC Health Check: Aplicacion oficial de Microsoft que evalua si el equipo cumple todos los requisitos de Windows 11.
  • Que es TPM: Chip de seguridad que resguarda claves de cifrado (BitLocker, Windows Hello). Es requisito obligatorio de Windows 11.
  • fTPM / Intel PTT: Son TPM integrados en el firmware de la CPU (AMD fTPM y Intel Platform Trust Technology). Las placas modernas los activan desde BIOS sin chip fisico.
  • Como activarlo en BIOS: Busca opciones como "Intel Platform Trust Technology", "AMD fTPM switch" o "Firmware TPM" y cambialas a Enabled.
  • Excepcion con Rufus: La opcion "Extended Windows 11 Installation" de Rufus genera un instalador que omite las comprobaciones de TPM, Secure Boot y RAM. Solo debe usarse en equipos parcialmente compatibles y asumiendo menor seguridad.
Verifica antes de instalar: si la placa no expone fTPM o TPM 2.0, Windows 11 no podra instalarse ni actualizarse por OTA. Comprobar con tpm.msc evita el error clasico "Este equipo no puede ejecutar Windows 11".
Instalacion de Linux (Ubuntu / Debian)

Ubuntu y Debian son las distribuciones mas sencillas para empezar. Con un pendrive booteable, el proceso completo lleva entre 20 y 30 minutos.

  • Descargar ISO: Desde ubuntu.com o debian.org. Elige la version LTS de Ubuntu para mayor estabilidad y soporte prolongado.
  • Crear el USB: Con Rufus o Ventoy desde Windows (usa el metodo de esta pagina). GPT + UEFI es lo recomendado en equipos modernos.
  • Arrancar desde USB: Entra al menu de arranque (F8/F11/F12) y selecciona el pendrive, o cambia el orden en BIOS.
  • Asistente: Elige idioma, distribucion de teclado y tipo de instalacion. En modo "Instalar Ubuntu" no toca el resto del disco.
  • Particionado automatico: Selecciona "Borrar disco e instalar Ubuntu" (o "Guided - use entire disk" en Debian). El asistente crea las particiones, incluida la de swap.
  • Usuario y contrasena: Crea tu cuenta; esa contrasena se usa con sudo para tareas administrativas.
  • GRUB: Al final se instala el gestor de arranque GRUB, que detecta otros sistemas y permite elegir en cada inicio.
bash · primeros comandos post-instalacion
# Actualizar lista de paquetes y sistema completo
  $ sudo apt update && sudo apt upgrade -y
  # Instalar herramientas basicas
  $ sudo apt install curl git htop neofetch -y
  # Limpiar paquetes que ya no se usan
  $ sudo apt autoremove
  # Ver un resumen del hardware y sistema
  $ neofetch
Nota: el particionado manual detallado esta en la seccion anterior de esta pagina (Particionado recomendado - Ubuntu/Debian).
Dual Boot Windows + Linux

El dual boot permite tener Windows y Linux en el mismo equipo, eligiendo en cada arranque cual sistema cargar. Es la opcion de muchos tecnicos que necesitan ambos mundos.

Requisitos previos:

  • Instalar Windows primero: Windows debe instalarse antes que Linux; su instalador sobrescribe el gestor de arranque existente.
  • Particionar antes: Deja espacio libre (por ejemplo 100 GB) para Linux o reduce una particion desde Administrador de discos de Windows.
  • Desactivar Fast Startup: Windows hiberna y deja el disco montado, lo que impide que Linux lo monte de forma segura.

Pasos:

  • Paso 1: Instala Windows y reduce una particion para dejar espacio libre.
  • Paso 2: Instala Linux con la opcion "Instalar junto a Windows" o el particionado manual en el espacio libre.
  • Paso 3: GRUB se instala y muestra un menu con ambos sistemas.
  • Paso 4: Desde el menu de arranque de la BIOS puedes fijar cual sistema se carga por defecto.

Riesgos a tener en cuenta:

  • BitLocker: Si Windows usa BitLocker, Linux no podra leer esas particiones por estar cifradas. Desactivalo antes de instalar.
  • Reloj RTC: Linux suele usar UTC y Windows hora local, causando desfases. En Linux: timedatectl set-local-rtc 1.
  • Actualizaciones de Windows: Una actualizacion importante puede sobrescribir GRUB. Reparalo arrancando desde el USB de Linux con grub-install.

Desinstalar el dual boot: Borra las particiones de Linux desde Administrador de discos y recupera el arranque de Windows con bootrec /fixmbr o bcdboot C:\Windows desde WinRE.

Precaucion: respalda tus datos antes de particionar o instalar, y desactiva BitLocker y el inicio rapido de Windows. Un error de particionado puede dejar inaccesible todo el disco.
Clonado y Migracion de Discos

Migrar de HDD a SSD es la mejora mas notable que se puede hacer en un equipo viejo. Macrium Reflect Free es la herramienta gratuita mas usada por tecnicos para clonar.

  • 1. Conectar el SSD: Instalalo en un slot SATA o M.2 libre y verifica que Windows lo reconozca en Administrador de discos.
  • 2. Abrir Macrium Reflect Free: En "Local Disks" elige el disco fuente y pulsa "Clone this disk".
  • 3. Elegir destino: Marca el SSD destino. "Copy partitions" replica el disco tal cual; "Shrink" ajusta las particiones al tamano del destino.
  • 4. Ajustar particiones: Arrastra o modifica el tamano de la particion del sistema para aprovechar toda la capacidad del SSD.
  • 5. Ejecutar la clonacion: Confirma y espera; puede tardar desde minutos hasta un par de horas segun la cantidad de datos.
  • 6. Arrancar desde el SSD: Cambia el orden de arranque en BIOS y verifica que Windows inicie con normalidad.
  • Clonar disco entero vs particion: Clonar el disco completo copia tambien las particiones de arranque y recuperacion. Clonar solo la particion del sistema suele dejar el equipo sin arrancar.
  • Migrar solo el SO: Si el sistema viejo esta muy sucio, reinstala Windows en el SSD y copia los datos manualmente. Es la ruta mas limpia y segura.
  • Que hacer con el disco viejo: Formatealo y usalo como disco de datos o respaldo, o conservalo intacto unos dias hasta confirmar que el SSD funciona bien.
Desconecta los discos de datos: durante la clonacion, deja solo el disco fuente y el destino conectados. Es facil seleccionar el disco equivocado como destino y perder datos de forma irreparable.
WSL - Subsistema Linux para Windows

WSL ejecuta un kernel Linux real dentro de Windows sin maquina virtual pesada ni arranque dual. Es ideal para desarrollo, practicas de redes y scripting.

  • Que es WSL2: Segunda generacion que usa un kernel virtualizado con compatibilidad completa de llamadas al sistema. Es el estandar desde Windows 10 version 2004.
  • Instalar: wsl --install instala WSL2, el kernel y Ubuntu por defecto en un solo comando, y pide reiniciar.
  • Instalar distros: wsl --list --online lista las disponibles; wsl --install -d Debian o -d kali-linux instalan otras.
  • Versiones: wsl --set-version Ubuntu 2 convierte una distro a WSL2; wsl --set-default-version 2 fija el valor por defecto.
  • Integracion de archivos: Desde Windows accedes a los archivos de Linux via \\wsl$\Ubuntu en el Explorador de archivos.
  • Comandos desde CMD: wsl ls -la o wsl bash -c "apt update" ejecutan Linux sin abrir la terminal de la distro.
  • Usos: Entorno de desarrollo, pruebas de redes, scripting con Bash y herramientas de diagnostico que no existen en Windows (nmap, netcat, curl de consola).
cmd · wsl desde powershell o cmd
# Instalar WSL2 con la distro por defecto
  > wsl --install
  # Ver las distros disponibles
  > wsl --list --online
  # Instalar Debian y fijar WSL2
  > wsl --install -d Debian
  > wsl --set-version Debian 2
  # Ejecutar un comando Linux desde CMD
  > wsl uname -a
  # Abrir la terminal de la distro
  > wsl -d Debian
