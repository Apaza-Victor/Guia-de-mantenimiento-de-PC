Inicio/Redes/Enrutamiento y Protocolos de Routing/Tablas de Rutas y Enrutamiento Basico

El enrutamiento es el proceso de elegir el camino por el cual viaja un paquete hasta su destino. En redes pequenas el router domestico decide todo automaticamente; en redes grandes hay routers dedicados que consultan su tabla de rutas antes de reenviar cada paquete.

  • Tabla de rutas: base de datos del router con las redes que conoce y por cual interfaz o salto llegar a ellas.
  • Ruta por defecto (default route): camino comodin (0.0.0.0/0) usado cuando el destino no coincide con ninguna entrada; en el hogar apunta al router del ISP.
  • Metrica: costo asociado a cada ruta; el router elige la de menor metrica (hops, ancho de banda, retardo).
  • Next-hop: direccion IP del router vecino al que se entrega el paquete para avanzar en el camino.
  • Rutas conectadas: redes directamente unidas a sus interfaces. Estaticas: cargadas a mano por el administrador. Dinamicas: aprendidas con protocolos como RIP, OSPF o EIGRP.

Ver la tabla de rutas - Windows y Linux
# Windows - mostrar la tabla de rutas IPv4
> route print
# Ruta por defecto tipica: destino 0.0.0.0, mascara 0.0.0.0, gateway 192.168.1.1

# Linux - mostrar la tabla de rutas
$ ip route
# Ejemplo de salida: default via 192.168.1.1 dev eth0
$ route -n            # Variante clasica con direcciones numericas
