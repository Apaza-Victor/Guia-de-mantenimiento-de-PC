DNS — Sistema de Nombres de Dominio (en profundidad)

Como traduce nombres · tipos de registro · resolucion completa

Inicio/Redes/TCP/IP y OSI/DNS — Sistema de Nombres de Dominio (en profundidad)

El DNS (Domain Name System) es "la guia telefonica de Internet": convierte nombres faciles de recordar (www.google.com) en direcciones IP. Sin DNS, tendriamos que memorizar numeros para cada sitio.

Tipos de registro DNS

RegistroFuncionEjemplo
ANombre → IPv4www → 142.250.217.14
AAAANombre → IPv6www → 2a00:1450:4001:82d::200e
CNAMEAlias de otro nombrewww → mi-dominio.com
MXServidor de correo del dominiomail.mi-dominio.com (prioridad 10)
NSServidores DNS autoritativosns1.mi-host.com
PTRIPv4 → nombre (resolucion inversa)14.217.250.142 → www
TXTTexto / verificaciones (SPF, DKIM)v=spf1 include:provider.com
SRVServicio especifico (VOIP, AD)_sip._tcp.mi-dominio.com
Resolucion en 4 pasos 1) Tu equipo pregunta al resolver (tu router o ISP). 2) El resolver consulta la raiz "." y luego el TLD (.com). 3) El TLD apunta al servidor autoritativo del dominio. 4) El autoritativo devuelve la IP (registro A). La respuesta se cachea (TTL) para acelerar consultas futuras.
DNS publico recomendado El DNS de tu ISP puede ser lento o censurado. Alternativas seguras: Cloudflare 1.1.1.1 / 1.0.0.1, Google 8.8.8.8 / 8.8.4.4, Quad9 9.9.9.9 (bloquea sitios maliciosos). En Windows: Panel de control → Adaptador de red → IPv4 → servidores DNS.
