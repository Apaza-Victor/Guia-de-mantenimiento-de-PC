IPv4 vs IPv6 — Comparativa completa

Redes · IPv4/IPv6 — Leccion 7 de 11

Inicio/Redes/IPv4/IPv6/IPv4 vs IPv6 — Comparativa completa
CaracteristicaIPv4IPv6
Tamano de direccion32 bits128 bits
NotacionDecimal punteado: 192.168.1.1Hexadecimal con dos puntos: 2001:db8::1
Direcciones disponibles~4.3 mil millones340 undecillones (2^128)
Mascara / prefijoMascara 255.255.255.0 o CIDR /24Solo CIDR: /64, /48, /56...
Configuracion de direccionesManual o DHCPSLAAC (automatica) o DHCPv6
BroadcastSi (255.255.255.255)No existe; se usa multicast
Resolucion de MAC (ARP)ARP por broadcastNDP de ICMPv6 (sin broadcast)
NATObligatorio para paliar la escasezInnecesario; cada equipo puede tener IP publica
FragmentacionLos routers pueden fragmentarSolo el emisor fragmenta (PMTUD)
Seguridad IPsecOpcionalDisenado como parte del protocolo
Cabecera20 bytes minimo (variable)40 bytes fija + extensiones
Checksum de cabeceraSiNo (se delega a capas superiores)
Loopback127.0.0.1::1
Direcciones especialesPrivadas RFC 1918, APIPA 169.254ULA fc00::/7, link-local fe80::
En la practica: hoy conviven ambos (dual stack). Tu equipo casi seguro tiene IPv4 e IPv6 a la vez; el sistema elige el mejor camino disponible para cada conexion.
