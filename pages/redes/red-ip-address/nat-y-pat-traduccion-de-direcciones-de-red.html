NAT y PAT — Traduccion de Direcciones de Red

Como una IP publica da servicio a toda la red · port forwarding

Inicio/Redes/Direccionamiento IP/NAT y PAT — Traduccion de Direcciones de Red

NAT (Network Address Translation) es el mecanismo que permite que decenas de dispositivos con IP privada compartan UNA sola IP publica. El router traduce las direcciones de cada paquete al pasar de la LAN a Internet y viceversa.

TerminoSignificadoEjemplo
NAT 1:1Una IP publica ↔ una IP privadaExponer un servidor web con IP propia
NAT estaticoTraduccion fija entre IPsUn servidor interno siempre alcanzable
NAT dinamicoIP publica de un pool al que se asignaISP con mas clientes que IPs
PAT / NAT overloadingMuchas IP privadas ↔ UNA IP publica usando puertosTu router de casa (el mas comun)
Port Forwarding (redireccion de puertos) Con PAT, para que Internet llegue a un servicio interno (ej: un servidor de juegos en tu PC) configuras en el router: puerto publico → IP privada + puerto interno. Ejemplo: 8080 → 192.168.1.50:8080. Sin esa regla, el router no sabe a cual de tus equipos entregar el trafico entrante.
DMZ (Zona Desmilitarizada) Algunos routers ofrecen "DMZ host": envía TODO el trafico no solicitado a un equipo. Suena facil, pero expone ese equipo completamente a Internet. Mejor usa Port Forwarding con puertos especificos que dejar DMZ activa.
