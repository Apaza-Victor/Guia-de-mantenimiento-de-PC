Monitoreo de Red

// No gestionas lo que no mides

Objetivo del monitoreo: detectar problemas ANTES de que los usuarios los vean (enlace caido, trafico anormal, disco del servidor lleno) y tener historicos para dimensionar la red.

Fundamentos de SNMP
El lenguaje de gestion de la red
▼
  • SNMP (Simple Network Management Protocol) permite a un gestor leer/alterar informacion de dispositivos (agent).
  • OID (Object Identifier): identificador numerico jerarquico de cada dato (ej. .1.3.6.1.2.1.1.5.0 = nombre del sistema).
  • Versiones: v1 (insegura), v2c (community string en claro), v3 (autenticacion y cifrado — la recomendada).
  • Community: en v1/v2c la contrasena se llama "community" (public/private por defecto). SIEMPRE cambiala o usa v3.
  • Trampas (traps): el agente avisa al gestor de eventos (link down, temperatura) sin que el gestor pregunte.
Herramienta rapida: con snmpwalk -v2c -c community IP (Net-SNMP) recorres todos los OIDs de un dispositivo y ves que datos expone. Ideal para saber que vas a poder monitorear antes de configurar el gestor.

Monitoreo de disponibilidad y alertas
Configura el "aviso" correcto
▼
  1. Agrega los hosts (IPs) de switches, routers, servidores y equipos criticos.
  2. Define el intervalo de chequeo: 1 minuto para criticos, 5 para el resto.
  3. Configura umbrales: latencia > 50ms en la LAN, perdida > 0%, CPU del switch > 80%.
  4. Configura las alertas: correo / Telegram / Slack. Evita el "ruido": agrupa y define mantenimientos programados para no recibir falsos positivos.
  5. Prueba una alerta manualmente (baja un enlace a proposito) para confirmar que el aviso llega.
Monitoreo de trafico — NetFlow / sFlow
Quien habla con quien y cuanto
▼
  • NetFlow/sFlow: protocolos que exportan estadisticas de flujo (IP origen/destino, puertos, bytes) desde switches/routers al colector.
  • Utilidad: detectar quien consume el ancho de banda (un PC con backup o malware), top talks, comportamiento inusual.
  • Alternativa en la LAN domestica: herramientas como ntopng o el trafico por IP del propio router dan una vista parcial.
  • SPAN (port mirroring): en switches gestionados, copiar todo el trafico de un puerto a otro para analizarlo con Wireshark sin interferir.
Privacidad: el monitoreo de trafico puede leer comunicaciones. Avisa a los usuarios, respeta la legislacion local y limita la captura a metadatos y volumenes, no al contenido.
Monitoreo en una red pequena o domestica
Lo practico sin servidores
▼
  • Log del router: activa los logs y revisa eventos de login, conexion WAN y dispositivos desconocidos.
  • Herramientas de escritorio: Angry IP Scanner o Advanced IP Scanner para ver que equipos hay conectados.
  • fping script: un cron que hace ping a tus equipos y te avisa por Telegram si alguno no responde.
  • Uptime Kuma: herramienta auto-hosteada muy simple para vigilar servicios (web, ping, puertos) con alertas.
  • Dashboards: un Raspberry Pi con Grafana + Prometheus da un panel moderno para la red de casa sin costo.
