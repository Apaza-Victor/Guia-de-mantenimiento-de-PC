Linux Server

Ubuntu Server · CentOS/Rocky · Debian

Inicio/Redes/SO de Red/Linux Server

Linux es el sistema operativo dominante en servidores a nivel mundial. Su estabilidad, seguridad, bajo consumo de recursos y licencia gratuita lo hacen ideal para servidores web, bases de datos, firewalls y contenedores.

Servicios comunes en Linux

Apache / Nginx

Servidores web de alto rendimiento. Apache: modular y flexible. Nginx: orientado a concurrencia masiva, proxy reverso y equilibrio de carga.

MySQL / PostgreSQL

Bases de datos relacionales para aplicaciones web, ERP y sistemas de gestion. PostgreSQL ofrece mayor funcionalidad SQL avanzada.

iptables / nftables

Firewalls nativos de Linux para filtrar trafico, configurar NAT, port forwarding y proteccion del servidor contra accesos no autorizados.

Docker / Podman

Contenedores ligeros para desplegar aplicaciones de forma aislada y reproducible. Kubernetes para orquestacion a gran escala.

bash · comandos esenciales de servidor Linux
# Instalar un servidor web Nginx
  $ sudo apt update && sudo apt install nginx -y
  $ sudo systemctl enable nginx
  $ sudo systemctl start nginx

  # Verificar servicios activos
  $ systemctl list-units --type=service --state=running

  # Abrir puerto en firewall (UFW)
  $ sudo ufw allow 80/tcp
  $ sudo ufw allow 443/tcp
  $ sudo ufw enable
