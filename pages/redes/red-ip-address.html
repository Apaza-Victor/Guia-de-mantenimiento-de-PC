¿Donde esta tu IP publica? La IP publica es la de tu router hacia Internet; TODOS los equipos de tu casa salen a Internet con la misma IP gracias al NAT. Busca "mi ip" en Google para verla. Esa IP identifica tu conexion, por eso los servicios de streaming la usan para detectar tu pais.
NAT y PAT — Traduccion de Direcciones de Red
Como una IP publica da servicio a toda la red · port forwarding
▼

NAT (Network Address Translation) es el mecanismo que permite que decenas de dispositivos con IP privada compartan UNA sola IP publica. El router traduce las direcciones de cada paquete al pasar de la LAN a Internet y viceversa.

TerminoSignificadoEjemplo
NAT 1:1Una IP publica ↔ una IP privadaExponer un servidor web con IP propia
NAT estaticoTraduccion fija entre IPsUn servidor interno siempre alcanzable
NAT dinamicoIP publica de un pool al que se asignaISP con mas clientes que IPs
PAT / NAT overloadingMuchas IP privadas ↔ UNA IP publica usando puertosTu router de casa (el mas comun)
Port Forwarding (redireccion de puertos) Con PAT, para que Internet llegue a un servicio interno (ej: un servidor de juegos en tu PC) configuras en el router: puerto publico → IP privada + puerto interno. Ejemplo: 8080 → 192.168.1.50:8080. Sin esa regla, el router no sabe a cual de tus equipos entregar el trafico entrante.
DMZ (Zona Desmilitarizada) Algunos routers ofrecen "DMZ host": envía TODO el trafico no solicitado a un equipo. Suena facil, pero expone ese equipo completamente a Internet. Mejor usa Port Forwarding con puertos especificos que dejar DMZ activa.
Subnetting Manual — Como Calcular una Subred a Mano
Formula de hosts · ejemplo paso a paso con /26 · tabla rapida de prefijos
▼

Antes de la calculadora, saber calcular a mano te permite responder rapido en entrevistas o sin herramientas: cuantas subredes, cuantos hosts, cual es el broadcast.

PrefijoMascaraHosts utilesUso tipico
/24255.255.255.0254Red local estandar
/25255.255.255.128126Dividir una red en 2 partes
/26255.255.255.19262Departamentos / segmentos pequenos
/27255.255.255.22430Redes muy pequenas
/30255.255.255.2522Enlaces punto a punto (router a router)
Formula de hosts: Hosts utilizables = 2^(32 - prefijo) - 2. El "-2" se debe a la direccion de red (primera) y de broadcast (ultima). Ejemplo /26: 2^6 - 2 = 62 hosts. Para calcular la direccion de red, aplica la mascara con AND binario sobre la IP.
Ejemplo: subred de 192.168.1.0/26
# Bloque /26 = 64 direcciones por subred
> Subred 1: 192.168.1.0    → hosts 1-62,  broadcast 63
> Subred 2: 192.168.1.64   → hosts 65-126, broadcast 127
> Subred 3: 192.168.1.128  → hosts 129-190, broadcast 191
> Subred 4: 192.168.1.192  → hosts 193-254, broadcast 255

Las herramientas de consola para detectar y resolver fallas

Estos comandos funcionan en Windows (cmd/PowerShell) y en Linux/macOS (terminal). Son el primer paso para diagnosticar "no tengo internet".

ComandoQue haceEjemplo de uso

Metodo de diagnostico en 4 pasos: 1) ipconfig — ¿tengo IP valida? (169.254.x.x = sin DHCP). 2) ping 127.0.0.1 — ¿funciona la NIC? 3) ping <tu-gateway> — ¿llego a mi router? 4) ping 8.8.8.8 — ¿tengo salida a Internet? Si falla el paso 3, es problema local; si falla solo el 4, es problema del ISP/DNS.
Subnetting Avanzado: VLSM y Supernetting (CIDR)

VLSM (Variable Length Subnet Mask) permite usar mascaras de longitud variable en la misma red: cada subred recibe el tamano que necesita en vez de bloques iguales. Asi se evita desperdiciar direcciones.

PasoNecesidadHostsPrefijoSubred asignada
1Ventas60/26 (62 utiles)192.168.1.0/26
2TI30/27 (30 utiles)192.168.1.64/27
3Admin25/27 (30 utiles)192.168.1.96/27
4Enlace router-router2/30 (2 utiles)192.168.1.128/30

Asi el bloque /24 se divide en subredes de distinto tamano sin desperdicio: 62 + 30 + 30 + 2 hosts utilizables, dejando el resto del rango libre para crecer.

Supernetting / agregacion CIDR: es lo contrario: unir varias redes contiguas en una ruta mas corta para resumir anuncios. Ejemplo: cuatro redes /24 (de 192.168.0.0/24 a 192.168.3.0/24) se anuncian como un solo bloque 192.168.0.0/22.

  • Mascaras wildcard: el complemento inverso de la mascara (255 - mascara). En ACLs y OSPF indican que bits comparar: ej. 0.0.0.255 para una /24.
  • Practica de diseno: 1) ordena las subredes de mayor a menor cantidad de hosts. 2) elige el prefijo que cubra cada una (hosts utiles = 2^n - 2). 3) asigna bloques contiguos desde la red base.
