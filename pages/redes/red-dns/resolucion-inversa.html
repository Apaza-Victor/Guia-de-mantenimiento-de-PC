Resolucion Inversa

Redes · DNS — Leccion 7 de 7

Inicio/Redes/DNS/Resolucion Inversa
  • Resolucion inversa (reverse DNS): traduce direcciones IP a nombres de dominio, lo contrario de una consulta normal.
  • Registro PTR: el registro DNS que almacena la asociacion IP → nombre. Se busca en la zona in-addr.arpa (IPv4) o ip6.arpa (IPv6).
  • Por que importa: muchos servidores de correo rechazan mensajes si el servidor emisor no tiene un PTR valido (anti-spam).
  • Seguridad: el uso compartido de IP (CGNAT, hosting compartido) dificulta la resolucion inversa porque la IP no puede tener un PTR unico.
cmd — consulta inversa
> nslookup 93.184.216.34
> nslookup -type=PTR 34.216.184.93.in-addr.arpa
bash — dig inverso (Linux/macOS)
$ dig -x 93.184.216.34
$ host 93.184.216.34
Configuracion: para configurar un registro PTR, necesitas acceso al servidor DNS autoritativo de la zona in-addr.arpa. En cloud (AWS, GCP, Azure) el registro PTR se configura en el panel del proveedor de IP.
