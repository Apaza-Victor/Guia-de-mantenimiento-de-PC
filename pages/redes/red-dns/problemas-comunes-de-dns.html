Problemas comunes de DNS

Redes · DNS — Leccion 6 de 7

Inicio/Redes/DNS/Problemas comunes de DNS
ProblemaSolucion
"El servidor DNS no responde"Reinicia router/modem, cambia a un DNS publico, verifica que el servicio DNS funcione.
Sitio no resuelve en un equipo pero si en otrosVacia la cache (ipconfig /flushdns), revisa el archivo hosts, cambia DNS del adaptador.
DNS cache poisoning / hijackingUsa DNSSEC si es posible, cambia DNS a uno confiable, evita redes con DNS manipulados.
Correo no llegaVerifica registros MX, SPF/TXT, DKIM y DMARC del dominio con dig -t MX.
DNS apunta a una IP viejaEspera el TTL (propagacion) o consulta con un DNS sin cache para verificar.
Filtrado de contenidos del proveedorCambia el DNS del router o equipo a uno publico (donde sea legal).
El archivo hosts (Windows: C:\Windows\System32\drivers\etc\hosts, Linux: /etc/hosts) tiene prioridad sobre el DNS: se usa para mapeos manuales y bloqueos locales.
