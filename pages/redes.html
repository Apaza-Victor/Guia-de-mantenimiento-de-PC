Fundamentos de Redes

TCP/IP · Modelo OSI · Tipos de red

🌐
¿Que es una red informatica? Un enlace a traves del cual dos o mas dispositivos se comunican mediante medios fisicos o inalambricos para intercambiar datos. La red domestica tipica: Proveedor de Internet → Router/Modem (procesa y redirige paquetes) → dispositivos conectados.
📶

💡
Mnemonico OSI (7→1) "All People Seem To Need Data Processing" → Application, Presentation, Session, Transport, Network, Data-link, Physical. TCP/IP se remonta a 1972 cuando el Departamento de Defensa de EE.UU. lo uso para enlazar su red.
📦
Contenido de los paquetes de red Cada paquete contiene Cabecera (Direcciones MAC + Direcciones IP + Puertos) + Datos + CRC (Comprobacion de Redundancia Ciclica para deteccion de errores). El overhead es toda la informacion adicional a los datos puros.

📡
Redes inalambricas vs cableadas Las redes cableadas poseen mayor tasa de transferencia de datos y mayor seguridad. Las inalambricas admiten mas tipos de dispositivos. Toda red inalambrica moderna tiene como base una interconexion de dispositivos cableados.

Topologias de Red

Cableadas e inalambricas · Ventajas · Desventajas · Redes mixtas

🚌 Bus / Lineal

Terminales y dispositivos conectados a una sola linea (bus) con terminador en cada extremo. Cable coaxial o Ethernet 10Base2. Un paquete se envia y es presentado a todas las computadoras; cada una analiza la direccion para saber si le corresponde.

+ Mas facil de armar y configurar + Menos cableado, mas economica − No regeneran senal: ruido y perdida de fidelidad − Un usuario desconectado corta la red

⭐ Estrella

La mas comun en LAN hogarenas y corporativas. Los equipos se interconectan mediante un hub o switch central. El hub repite y potencia la senal recibida, detecta errores y los corrige. La perdida de un nodo no afecta al resto.

+ Si un terminal falla, la red sigue + No se pierde conexion al agregar o retirar nodos − El punto critico es el hub/switch central − Mas cableado; cada PC necesita cable independiente al hub

💍 Anillo

Los dos terminales extremos estan interconectados formando un circulo. La senal viaja en un solo sentido. Cada computadora actua como repetidor y regenerador de senal, reduciendo el trayecto recorrido.

+ Problemas faciles de detectar y resolver + La informacion sufre menos ruidos − Incorporar una nueva PC rompe el anillo temporalmente − El soporte tecnico requiere desactivar la red

🕸 Mesh (Malla)

Todas las computadoras estan interconectadas entre si sin intermediarios. La red se satura rapidamente porque el envio de informacion a otra maquina provoca un efecto en cadena. Muy costosa de implementar.

+ Todas las computadoras interconectadas sin intermediarios − Conexiones costosas y demasiado cableado − Cada dispositivo necesita tantas placas como computadoras haya

📶 Ad-Hoc (inalambrica)

Conexion inalambrica punto a punto sin medios fisicos, a traves de senales de radio. Los equipos deben estar dentro de un rango determinado; a medida que se alejan, se pierde la fidelidad de la senal.

+ Sin medios fisicos para la interconexion + Movilidad y versatilidad dentro del rango − Rango muy limitado de trabajo − Velocidad inferior a la de redes fisicas cableadas

🏗 Infraestructura (inalambrica)

Requiere un elemento central que coordine y sirva como punto base de informacion: una estacion central inalambrica (access point). Combina conexiones Ethernet e inalambricas. Si todos los elementos trabajan bajo el mismo SSID, todos tendran acceso.

+ Combina Ethernet e inalambrico eficientemente + Gran cobertura y escalabilidad − Requiere access point central coordinador
🔀
Redes Mixtas Para seleccionar la topologia mas conveniente, considera: capacidad maxima de computadoras disponibles, tasa de transferencia de informacion requerida y distancia entre equipos. El presupuesto disponible es un factor determinante.

Dispositivos de Red

NIC · Switch · Router · Hub · Repetidor · Gateway · Cables

🖧 Tarjeta de Red (NIC)

Placa PCB de insercion interna o externa. Interfaces PCI, PCIe, USB o ExpressCard. Puerto Ethernet o fibra optica con indicador luminico de actividad. Velocidad 10–1000 Mbps. Direccion MAC unica incorporada en fabricacion.

🔀 Switch (Conmutador)

Dispositivo puente con tabla de direcciones MAC que administra datos por direccion origen→destino. Disminuye colisiones, aumenta ancho de banda y mejora simultaneidad de transmisiones vs hub. Los "inteligentes" permiten configurar VLANs.

📶 Router

Opera a nivel de direcciones IP (capa 3). Permite interconexion entre subredes y WAN. Diseña tabla origen/destino trazando posibles rutas. Puede integrar switch, hub, firewall y manejar LAN + WLAN simultaneamente.

🔌 Hub (Concentrador)

Actualmente en desuso pero aun util en pequenas redes hogarenas. Conecta varias computadoras en topologia estrella. Retransmite los datos recibidos amplificados y limpiados de errores.

📡 Repetidor / Access Point

Recibe senal media o baja y la retransmite amplificada. Bajo estas caracteristicas puede considerarse al access point como un repetidor. Recibe senales de medios inalambricos o cableados y las retransmite.

🌉 Gateway

Dispositivo nodo dentro de la red local que sirve para enlazar con otra red de protocolo diferente. Puede ser un modem, router o computadora. El ejemplo mas habitual: conexion de una red hogarenia a Internet.

Tipos de Cables de Red y Como Armar un UTP
UTP · STP · FTP · Fibra optica · Coaxial · RJ-45
▼

UTP — Unshielded Twisted Pair

Filamentos de cobre entrelazados. Sin blindaje (mas susceptible a interferencias electromagneticas). De facil manejo y aplicacion. Uso habitual en redes locales. El mas economico.

STP — Shielded Twisted Pair

Cada par esta aislado del otro por una malla individual que disminuye considerablemente la interferencia. Mas costoso que UTP pero ofrece mayor proteccion contra la diafonia.

FTP — Foiled Twisted Pair

Blindaje global que abarca todo el conjunto de pares trenzados (no por filamentos individuales como STP). El blindaje global protege contra interferencias externas. Precio intermedio entre UTP y STP.

Fibra Optica

Nucleo de vidrio o material plastico. Usa senal luminica (impulsos de luz) en lugar de electrica. Senales concentradas que no desaparecen hasta llegar a destino. Ideal para conexiones extensas y de alta velocidad.

Cable Coaxial

Nucleo central de cobre + dielectrico + malla (cuerpo de retorno de datos) + malla plastica exterior. Habituales para senales televisivas por cable y cablemodem.

Categorias UTP

CAT3: 10 Mbps. CAT5: 100 Mbps (100BaseTX). CAT5e: 1 Gbps (1000BaseT). CAT6: 1–10 Gbps (a 55m). CAT6a: 10 Gbps (100m). CAT7: 10 Gbps blindado.

🔧
Armar un cable UTP RJ-45 (T568A / T568B) Materiales: pinza crimpeadora, tester de red, fichas RJ-45 y cable UTP CAT5/6. ① Retirar ~2 cm de vaina protectora con la crimpeadora. ② Separar los 4 pares y ordenar segun la norma deseada. ③ Colocar en la ficha RJ-45 en el orden correcto. ④ Insertar la ficha en la crimpeadora y presionar para el cierre y fijacion del cable. ⑤ Repetir en el extremo opuesto. ⑥ Verificar con tester de red. Agregar 10–20% de longitud extra para imprevistos.

Comandos de Red

ping · ipconfig · tracert · nslookup · netstat · arp · nmap

ping · ipconfig · tracert
# PING — conectividad y latencia
> ping 8.8.8.8                  # Ping basico (4 pings en Windows)
> ping -t google.com           # Ping continuo (Ctrl+C para detener)
> ping -n 10 google.com        # 10 pings Windows
$ ping -c 10 google.com        # 10 pings Linux/macOS
# TTL=64 → Linux/macOS  |  TTL=128 → Windows
# Latencia ideal: <10ms LAN · <50ms ISP · <150ms internet
# Request timeout → host bloqueado o inaccesible

# IPCONFIG — configuracion de red Windows
> ipconfig                  # Ver IPs y adaptadores
> ipconfig /all            # MAC, DHCP, DNS servers
> ipconfig /release        # Liberar IP de DHCP
> ipconfig /renew          # Solicitar nueva IP al DHCP
> ipconfig /flushdns       # Limpiar cache DNS local
$ ip addr                   # Linux: equivalente a ipconfig
$ ip route show            # Tabla de enrutamiento Linux

# TRACERT — ruta de paquetes
> tracert google.com         # Windows: muestra cada salto (hop)
> tracert -d google.com     # Sin resolucion DNS (mas rapido)
$ traceroute google.com     # Linux/macOS
$ mtr google.com            # ping + traceroute en tiempo real
# * * * = router no responde ICMP (no siempre indica fallo)
nslookup · netstat · arp · wifi · reset
# NSLOOKUP / DIG — consultas DNS
> nslookup google.com           # Consulta DNS por defecto
> nslookup google.com 8.8.8.8   # Usar DNS de Google
> nslookup -type=MX gmail.com   # Registros de correo
$ dig +short google.com         # Solo la IP resultante
$ dig -x 8.8.8.8               # Reverse DNS lookup

# NETSTAT — conexiones y puertos
> netstat -ano                  # Conexiones con PID
> netstat -ano | findstr :80   # Proceso usando el puerto 80
> netstat -a                    # Ver si hay virus/malware por conexiones inusuales
$ ss -tulpn                    # Linux: puertos en escucha con proceso

# ARP — tabla de direcciones MAC
> arp -a                       # Ver tabla ARP (IP → MAC)
> arp -d 192.168.1.100         # Eliminar entrada ARP

# WIFI Y RESET DE PILA DE RED
> netsh wlan show profiles           # Redes WiFi guardadas
> netsh wlan show profile name="MiRed" key=clear  # Ver contrasena
> netsh interface ip reset           # Resetear TCP/IP stack
> netsh winsock reset               # Resetear Winsock (problemas de conexion)

# NMAP — escaneo de red (instalar por separado)
$ nmap -sn 192.168.1.0/24       # Ping scan: hosts activos en la red
$ nmap -sV 192.168.1.1          # Detectar servicios y versiones
🔍
Flujo de solucion de problemas de conectividad ① Deshabilitar y rehabilitar la placa de red en Centro de Redes. ② ipconfig /release + /renew + /flushdns. ③ Apagar y reiniciar el router/modem. ④ Probar el cable de red con un tester de red. ⑤ Conectar el modem directamente a la PC para descartar router. ⑥ Cambiar entre Ethernet y WiFi para descartar placa de red. ⑦ Si persiste, contactar al ISP ya que la falla puede estar en el DSLAM de la central telefonica.
