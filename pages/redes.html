Fundamentos de Redes

TCP/IP · Modelo OSI · Tipos de red

🌐
¿Que es una red informatica? Un enlace a traves del cual dos o mas dispositivos se comunican mediante medios fisicos o inalambricos para intercambiar datos. La red domestica tipica: Proveedor de Internet → Router/Modem (procesa y redirige paquetes) → dispositivos conectados.
📶

💡
Mnemonico OSI (7→1) "All People Seem To Need Data Processing" → Application, Presentation, Session, Transport, Network, Data-link, Physical. TCP/IP se remonta a 1972 cuando el Departamento de Defensa de EE.UU. lo uso para enlazar su red.
📦
Contenido de los paquetes de red Cada paquete contiene Cabecera (Direcciones MAC + Direcciones IP + Puertos) + Datos + CRC (Comprobacion de Redundancia Ciclica para deteccion de errores). El overhead es toda la informacion adicional a los datos puros.

Topologias de Red

Cableadas e inalambricas · Ventajas · Desventajas · Redes mixtas

🚌 Bus / Lineal

Terminales y dispositivos conectados a una sola linea (bus) con terminador en cada extremo. Cable coaxial o Ethernet 10Base2. Un paquete se envia y es presentado a todas las computadoras; cada una analiza la direccion para saber si le corresponde.

+ Mas facil de armar y configurar + Menos cableado, mas economica − No regeneran senal: ruido y perdida de fidelidad − Un usuario desconectado corta la red

⭐ Estrella

La mas comun en LAN hogarenas y corporativas. Los equipos se interconectan mediante un hub o switch central. El hub repite y potencia la senal recibida, detecta errores y los corrige. La perdida de un nodo no afecta al resto.

+ Si un terminal falla, la red sigue + No se pierde conexion al agregar o retirar nodos − El punto critico es el hub/switch central − Mas cableado; cada PC necesita cable independiente al hub

💍 Anillo

Los dos terminales extremos estan interconectados formando un circulo. La senal viaja en un solo sentido. Cada computadora actua como repetidor y regenerador de senal, reduciendo el trayecto recorrido.

+ Problemas faciles de detectar y resolver + La informacion sufre menos ruidos − Incorporar una nueva PC rompe el anillo temporalmente − El soporte tecnico requiere desactivar la red

🕸 Mesh (Malla)

Todas las computadoras estan interconectadas entre si sin intermediarios. La red se satura rapidamente porque el envio de informacion a otra maquina provoca un efecto en cadena. Muy costosa de implementar.

+ Todas las computadoras interconectadas sin intermediarios − Conexiones costosas y demasiado cableado − Cada dispositivo necesita tantas placas como computadoras haya

📶 Ad-Hoc (inalambrica)

Conexion inalambrica punto a punto sin medios fisicos, a traves de senales de radio. Los equipos deben estar dentro de un rango determinado; a medida que se alejan, se pierde la fidelidad de la senal.

+ Sin medios fisicos para la interconexion + Movilidad y versatilidad dentro del rango − Rango muy limitado de trabajo − Velocidad inferior a la de redes fisicas cableadas

🏗 Infraestructura (inalambrica)

Requiere un elemento central que coordine y sirva como punto base de informacion: una estacion central inalambrica (access point). Combina conexiones Ethernet e inalambricas. Si todos los elementos trabajan bajo el mismo SSID, todos tendran acceso.

+ Combina Ethernet e inalambrico eficientemente + Gran cobertura y escalabilidad − Requiere access point central coordinador
🔀
Redes Mixtas Para seleccionar la topologia mas conveniente, considera: capacidad maxima de computadoras disponibles, tasa de transferencia de informacion requerida y distancia entre equipos. El presupuesto disponible es un factor determinante.

Dispositivos de Red

NIC · Switch · Router · Hub · Repetidor · Gateway · Cables

🖧 Tarjeta de Red (NIC)

Placa PCB de insercion interna o externa. Interfaces PCI, PCIe, USB o ExpressCard. Puerto Ethernet o fibra optica con indicador luminico de actividad. Velocidad 10–1000 Mbps. Direccion MAC unica incorporada en fabricacion.

🔀 Switch (Conmutador)

Dispositivo puente con tabla de direcciones MAC que administra datos por direccion origen→destino. Disminuye colisiones, aumenta ancho de banda y mejora simultaneidad de transmisiones vs hub. Los "inteligentes" permiten configurar VLANs.

📶 Router

Opera a nivel de direcciones IP (capa 3). Permite interconexion entre subredes y WAN. Diseña tabla origen/destino trazando posibles rutas. Puede integrar switch, hub, firewall y manejar LAN + WLAN simultaneamente.

🔌 Hub (Concentrador)

Actualmente en desuso pero aun util en pequenas redes hogarenas. Conecta varias computadoras en topologia estrella. Retransmite los datos recibidos amplificados y limpiados de errores.

📡 Repetidor / Access Point

Recibe senal media o baja y la retransmite amplificada. Bajo estas caracteristicas puede considerarse al access point como un repetidor. Recibe senales de medios inalambricos o cableados y las retransmite.

🌉 Gateway

Dispositivo nodo dentro de la red local que sirve para enlazar con otra red de protocolo diferente. Puede ser un modem, router o computadora. El ejemplo mas habitual: conexion de una red hogarenia a Internet.

Tipos de Cables de Red y Como Armar un UTP
UTP · STP · FTP · Fibra optica · Coaxial · RJ-45
▼

UTP — Unshielded Twisted Pair

Filamentos de cobre entrelazados. Sin blindaje (mas susceptible a interferencias electromagneticas). De facil manejo y aplicacion. Uso habitual en redes locales. El mas economico.

STP — Shielded Twisted Pair

Cada par esta aislado del otro por una malla individual que disminuye considerablemente la interferencia. Mas costoso que UTP pero ofrece mayor proteccion contra la diafonia.

FTP — Foiled Twisted Pair

Blindaje global que abarca todo el conjunto de pares trenzados (no por filamentos individuales como STP). El blindaje global protege contra interferencias externas. Precio intermedio entre UTP y STP.

Fibra Optica

Nucleo de vidrio o material plastico. Usa senal luminica (impulsos de luz) en lugar de electrica. Senales concentradas que no desaparecen hasta llegar a destino. Ideal para conexiones extensas y de alta velocidad.

Cable Coaxial

Nucleo central de cobre + dielectrico + malla (cuerpo de retorno de datos) + malla plastica exterior. Habituales para senales televisivas por cable y cablemodem.

Categorias UTP

CAT3: 10 Mbps. CAT5: 100 Mbps (100BaseTX). CAT5e: 1 Gbps (1000BaseT). CAT6: 1–10 Gbps (a 55m). CAT6a: 10 Gbps (100m). CAT7: 10 Gbps blindado.

🔧
Armar un cable UTP RJ-45 (T568A / T568B) Materiales: pinza crimpeadora, tester de red, fichas RJ-45 y cable UTP CAT5/6. ① Retirar ~2 cm de vaina protectora con la crimpeadora. ② Separar los 4 pares y ordenar segun la norma deseada. ③ Colocar en la ficha RJ-45 en el orden correcto. ④ Insertar la ficha en la crimpeadora y presionar para el cierre y fijacion del cable. ⑤ Repetir en el extremo opuesto. ⑥ Verificar con tester de red. Agregar 10–20% de longitud extra para imprevistos.

Comandos de Red

ping · ipconfig · tracert · nslookup · netstat · arp · nmap

ping · ipconfig · tracert
# PING — conectividad y latencia
> ping 8.8.8.8                  # Ping basico (4 pings en Windows)
> ping -t google.com           # Ping continuo (Ctrl+C para detener)
> ping -n 10 google.com        # 10 pings Windows
$ ping -c 10 google.com        # 10 pings Linux/macOS
# TTL=64 → Linux/macOS  |  TTL=128 → Windows
# Latencia ideal: <10ms LAN · <50ms ISP · <150ms internet
# Request timeout → host bloqueado o inaccesible

# IPCONFIG — configuracion de red Windows
> ipconfig                  # Ver IPs y adaptadores
> ipconfig /all            # MAC, DHCP, DNS servers
> ipconfig /release        # Liberar IP de DHCP
> ipconfig /renew          # Solicitar nueva IP al DHCP
> ipconfig /flushdns       # Limpiar cache DNS local
$ ip addr                   # Linux: equivalente a ipconfig
$ ip route show            # Tabla de enrutamiento Linux

# TRACERT — ruta de paquetes
> tracert google.com         # Windows: muestra cada salto (hop)
> tracert -d google.com     # Sin resolucion DNS (mas rapido)
$ traceroute google.com     # Linux/macOS
$ mtr google.com            # ping + traceroute en tiempo real
# * * * = router no responde ICMP (no siempre indica fallo)
nslookup · netstat · arp · wifi · reset
# NSLOOKUP / DIG — consultas DNS
> nslookup google.com           # Consulta DNS por defecto
> nslookup google.com 8.8.8.8   # Usar DNS de Google
> nslookup -type=MX gmail.com   # Registros de correo
$ dig +short google.com         # Solo la IP resultante
$ dig -x 8.8.8.8               # Reverse DNS lookup

# NETSTAT — conexiones y puertos
> netstat -ano                  # Conexiones con PID
> netstat -ano | findstr :80   # Proceso usando el puerto 80
> netstat -a                    # Ver si hay virus/malware por conexiones inusuales
$ ss -tulpn                    # Linux: puertos en escucha con proceso

# ARP — tabla de direcciones MAC
> arp -a                       # Ver tabla ARP (IP → MAC)
> arp -d 192.168.1.100         # Eliminar entrada ARP

# WIFI Y RESET DE PILA DE RED
> netsh wlan show profiles           # Redes WiFi guardadas
> netsh wlan show profile name="MiRed" key=clear  # Ver contrasena
> netsh interface ip reset           # Resetear TCP/IP stack
> netsh winsock reset               # Resetear Winsock (problemas de conexion)

# NMAP — escaneo de red (instalar por separado)
$ nmap -sn 192.168.1.0/24       # Ping scan: hosts activos en la red
$ nmap -sV 192.168.1.1          # Detectar servicios y versiones
🔍
Flujo de solucion de problemas de conectividad ① Deshabilitar y rehabilitar la placa de red en Centro de Redes. ② ipconfig /release + /renew + /flushdns. ③ Apagar y reiniciar el router/modem. ④ Probar el cable de red con un tester de red. ⑤ Conectar el modem directamente a la PC para descartar router. ⑥ Cambiar entre Ethernet y WiFi para descartar placa de red. ⑦ Si persiste, contactar al ISP ya que la falla puede estar en el DSLAM de la central telefonica.

Sistemas Operativos de Red

Windows Server · Linux Server · NAS OS · Comparativa de uso

Que es un SO de red? Un sistema operativo de red gestiona hardware, servicios de comunicacion entre multiples equipos, procesamiento distribuido, seguridad de datos y recuperacion ante fallos. A diferencia de un SO de escritorio, esta optimizado para ejecutar servicios 24/7 y manejar multiples conexiones simultaneas.
Windows Server
Roles esenciales · Active Directory · DNS · DHCP · IIS
▼

Windows Server es el sistema operativo de red de Microsoft disenado para entornos corporativos. Ofrece una interfaz grafica familiar y herramientas de administracion centralizadas. Cada version incluye roles especificos que se instalan segun la necesidad del servidor.

Roles principales de Windows Server

Active Directory DS

Servicio de dominio que centraliza la autenticacion y autorizacion de usuarios y equipos. Permite politicas de grupo (GPO), gestión de cuentas y seguridad en toda la red corporativa.

DNS Server

Resolucion de nombres de dominio a direcciones IP. Servidor DNS primario, secundario o de caché. Fundamental para que los servicios internos (AD, SharePoint, Exchange) funcionen correctamente.

DHCP Server

Asigna direcciones IP automaticamente a los dispositivos de la red. Gestion de rangos, reservas, exclusiones y opciones de red (gateway, DNS, dominio).

IIS (Web Server)

Servidor web integrado para alojar sitios web, aplicaciones ASP.NET y servicios WCF. Soporte para HTTPS, certificados SSL y reescritura de URL.

LicenciamientoWindows Server se licencia por nucleos fisicos del servidor. La edicion Essentials (hasta 25 usuarios/50 dispositivos) es ideal para pequenas empresas. Las ediciones Standard y Datacenter permiten virtualizacion con licencia incluida.

Ubuntu Server · CentOS/Rocky · Debian

Linux es el sistema operativo dominante en servidores a nivel mundial. Su estabilidad, seguridad, bajo consumo de recursos y licencia gratuita lo hacen ideal para servidores web, bases de datos, firewalls y contenedores.

Servicios comunes en Linux

Apache / Nginx

Servidores web de alto rendimiento. Apache: modular y flexible. Nginx: orientado a concurrencia masiva, proxy reverso y equilibrio de carga.

MySQL / PostgreSQL

Bases de datos relacionales para aplicaciones web, ERP y sistemas de gestion. PostgreSQL ofrece mayor funcionalidad SQL avanzada.

NAS OS — Sistemas de Almacenamiento en Red
TrueNAS · Synology DSM · OpenMediaVault
▼

Un NAS (Network Attached Storage) es un dispositivo dedicado al almacenamiento y comparticion de archivos en red. Su sistema operativo esta optimizado para gestionar discos, RAID, cuotas de usuario y servicios de respaldo.

TrueNAS (iXsystems)

Basado en FreeBSD. TrueNAS CORE (gratuito) con ZFS para integridad de datos, snapshots y compresion. TrueNAS SCALE (Linux) agrega contenedores Docker y virtualizacion KVM. Ideal para entornos que requieren maxima fiabilidad.

Synology DSM

Interfaz web muy pulida y facil de usar. Paquetes de aplicaciones (Surveillance Station, Drive, MailPlus). Soporte Btrfs, snapshots y sincronizacion remota. Perfecto para PYMES y uso doméstico.

OpenMediaVault

Basado en Debian Linux, completamente gratuito y de codigo abierto. Interfaz web sencilla para gestionar SMB/NFS, plugins de Docker, rsync y BTsync. Ideal para montar un NAS con hardware antiguo o Raspberry Pi.

ZFS vs Btrfs en NASZFS (TrueNAS): snapshots eficientes, compresion LZ4, deduplicacion, reparacion automatica de datos corrompidos. Btrfs (Synology): snapshots rapidos, clonacion eficiente, pero con historial de estabilidad en RAID 5/6. Para datos criticos, ZFS es la opcion mas robusta.

Componentes de Red

Servidor · Estacion de trabajo · Nodo · Tarjeta de Red (NIC)

Que es un componente de red? Los componentes de una red tienen funciones especificas y se utilizan dependiendo de las necesidades y los recursos economicos de quien se desea conectar. Para elegirlos se requiere conocer las caracteristicas tecnicas de cada componente.
Servidor
Definicion · tipos · servicios que ofrece
▼

Son computadoras que controlan las redes y se encargan de permitir o no el acceso de los usuarios a los recursos. Tambien controlan los permisos que determinan si un nodo puede o no pertenecer a una red. La finalidad de los servidores es controlar el funcionamiento de una red.

Tipo de ServidorFuncion
Servidor de ArchivosAlmacena y comparte archivos en la red. Gestiona permisos de acceso y cuotas de disco para los usuarios.
Servidor WebAloja sitios web y servicios HTTP/HTTPS. Ejemplos: Apache, Nginx, IIS.
Servidor de Base de DatosGestiona bases de datos centralizadas (MySQL, PostgreSQL, SQL Server). Permite consultas concurrentes desde multiples clientes.
Servidor ProxyActua como intermediario entre los clientes e Internet. Filtra contenido, cachea paginas y mejora la seguridad de la red.
Servidor de CorreoGestiona envio y recepcion de correo electronico via SMTP, IMAP y POP3. Ejemplos: Exchange, Postfix, Zimbra.
Estacion de Trabajo
Computadoras conectadas a la red que no la controlan
▼

Es el nombre que reciben las computadoras conectadas a una red pero que no pueden controlarla, ni alguno de sus nodos o recursos de la misma. Cualquier computadora puede ser estacion de trabajo, siempre que este conectada y se comunique con la red. Son los dispositivos finales que consumen los servicios que ofrecen los servidores.

Nodo de Red
Cualquier elemento conectado y comunicado en la red
▼

Es cualquier elemento que se encuentre conectado y comunicado a una red. Los perifericos que se conectan a una computadora se convierten en nodo si estan conectados a la red y pueden compartir sus servicios para ser utilizados por los usuarios, como impresoras o carpetas compartidas. Cada nodo tiene una direccion unica (MAC) que lo identifica en la red.

Tarjeta de Red (NIC)
Network Interface Card · direccion MAC · velocidades
▼

Son tarjetas de circuitos integrados que se insertan en los puertos de expansion de la placa madre y cuya funcion es recibir el cable que conecta a la computadora con una red informatica. Placa PCB de insercion interna o externa con interfaces PCI, PCIe, USB o ExpressCard.

CaracteristicaDetalle
Direccion MACDireccion fisica unica de 48 bits incorporada en fabricacion (例: 00:1A:2B:3C:4D:5E)
Velocidades10 Mbps · 100 Mbps (Fast Ethernet) · 1000 Mbps (Gigabit) · 10 Gbps
InterfacesPCIe x1 (comun) · USB externa · Integrada en placa madre
PuertoEthernet RJ-45 con indicador luminico de actividad
MAC vs IP La direccion MAC es permanente y fisica (grabada en la NIC). La direccion IP es logica y puede cambiar segun la red. ARP resuelve IP a MAC en la red local.

Medios de Transmision

Coaxial · Par trenzado · Fibra optica · Inalambrico

Medios de transmision Estos elementos hacen posible la comunicacion entre dos computadoras. Son cables que conectan a las computadoras y a traves de los cuales viaja la informacion. Su eleccion depende de las necesidades de la comunicacion de red.
Cable Coaxial
RG-6 · RG-59 · nucleo de cobre · malla de retorno
▼

Constituido por un hilo principal de cobre cubierto por una capa plastica, rodeada por una pelicula reflejante que reduce las interferencias. Alrededor de ella existe una malla de hilos metalicos, y todo esto esta cubierto por una capa de hule que protege a los conductores.

RG-6

Cable coaxial de mayor grosor (75 ohm). Usado para TV por cable, Internet via cablemodem y senales de video HD. Mayor capacidad de transferencia y menor atenuacion que RG-59.

RG-59

Cable coaxial mas delgado (75 ohm). Usado para video analogico CCTV y conexiones de corta distancia. Menor ancho de banda que RG-6, mas susceptible a interferencias.

Par Trenzado
UTP · STP · FTP · Categorias CAT5 a CAT8
▼

Se utiliza para la conexion de redes; es el cable que tiene 4 pares de hilos, aunque existen 3 variaciones principales:

UTP — Unshielded Twisted Pair

Par trenzado no apantallado. La variante mas utilizada por su bajo costo, facil manejo y porque no requiere herramientas especiales. Sin blindaje (mas susceptible a interferencias electromagneticas).

STP — Shielded Twisted Pair

Par trenzado apantallado. Tiene una malla metalica que cubre cada par de cables, ademas de una pelicula reflejante que evita interferencias. Mas costoso pero ofrece mayor proteccion contra diafonia.

FTP — Foiled Twisted Pair

Par trenzado con pantalla global. Tiene una pelicula reflejante que cubre a cada uno de los pares de cables (no por filamentos individuales como STP). Precio intermedio entre UTP y STP.

Fibra Optica
Monomodo vs Multimodo · senal luminica · alta velocidad
▼

Nucleo de vidrio o material plastico que usa senal luminica (impulsos de luz) en lugar de electrica. Senales concentradas que no desaparecen hasta llegar a destino. Ideal para conexiones extensas y de alta velocidad. Resistente a la corrosion y a las altas temperaturas.

Fibra Monomodo (SMF)

Nucleo muy estrecho (~9 micras). Un solo haz de luz viaja por el nucleo. Alcances de hasta 100+ km. Usada en conexiones de larga distancia, telecomunicaciones y backbones de Internet.

Fibra Multimodo (MMF)

Nucleo mas amplio (50-62.5 micras). Multiples haces de luz rebotan dentro del nucleo. Alcances de hasta 2 km. Usada en centros de datos, redes LAN y distancias cortas-medias.

Desventajas de la fibra optica Su costo es elevado ya que para su elaboracion se requiere vidrio de alta calidad. Ademas es sumamente fragil de manipular durante su fabricacion. Sin embargo, su inmunidad a interferencias electromagneticas y su enorme ancho de banda la hacen insustituible en redes modernas.
Comunicacion Inalambrica
WiFi · Bluetooth · Infrarrojos
▼

La comunicacion inalambrica es la transferencia de informacion sin ninguna conexion fisica entre el emisor y el receptor, que utilizan el espectro de frecuencia de radio, hardware, software y diversas tecnologias para transmitir informacion.

WiFi (WLAN)

Wireless Fidelity — tecnologia de comunicacion inalambrica mediante ondas de radio. Requiere un punto de acceso (access point) conectado al modem y un dispositivo WiFi conectado al equipo. Estandares: 802.11n/ac/ax (Wi-Fi 4/5/6).

Bluetooth

Tecnologia de red inalambrica de corto alcance que conecta dispositivos sin cables, sin requerir linea de visualizacion directa. Transmite voz o datos entre equipos con circuitos de radio de bajo costo, en un rango de 10 a 100 metros, usando poca energia.

Infrarrojos

Permite establecer una conexion directa entre dos dispositivos habilitados para infrarrojos sin necesidad de cables o hardware de red. Se alinean dos dispositivos para establecer el vinculo. Alcance muy limitado y en desuso actualmente.

Que es la arquitectura de red? Es el plan con el que se conectan los protocolos y otros programas de software. La arquitectura de una red viene definida por su topologia, el metodo de acceso a la red y los protocolos de comunicacion.

Dominio de Broadcast
Area de difusion · colision de paquetes
▼

Un dominio de broadcast es el conjunto de todos los dispositivos que pueden recibir paquetes de difusion (broadcast) entre si. En una LAN con un switch, todos los puertos pertenecen al mismo dominio de broadcast. Los routers separan dominios de broadcast, limitando el trafico innecesario.

Guia Visual de Puertos

USB · Video · Red · Audio · Serial · Almacenamiento · Expansion

Puertos USB
USB-A · USB-B · USB-C · Mini-USB · Micro-USB
▼

USB-A

Conector rectangular estandar, el mas comun en PCs. No reversible — solo se inserta en una orientacion. Presente en teclados, ratones, memorias USB y la mayoria de perifericos.

USB-B

Conector cuadrado con esquinas biseladas. Usado en impresoras, escaneres, hubs USB y monitores. Extremo dispositivo del cable USB-A a USB-B. Muy robusto.

USB-C

Conector reversible de 24 pines. Soporta datos (USB4: 40 Gbps), video (Alt Mode: DP/HDMI), carga (Power Delivery hasta 240W) y Thunderbolt. Estandar universal moderno.

Mini-USB

Version compacta con 5 pines. Fue popular en camaras digitales y reproductores MP3. En desuso, reemplazado por Micro-USB y USB-C.

Micro-USB

Version compacta con 5 pines. Fue el estandar para telefonos Android antes de USB-C. Aun presente en dispositivos economicos y gadgets.

Puertos de Video
HDMI · DisplayPort · VGA · DVI
▼

HDMI (High Definition Multimedia)

Transmite audio y video en un cable. Tipos: Standard (A), Mini (C), Micro (D). Versiones: 1.4 (4K@30Hz), 2.0 (4K@60Hz), 2.1 (8K@60Hz, 4K@120Hz). Estandar en TVs, monitores y GPUs.

DisplayPort (DP)

Interfaz digital de alta gama para video y audio. Superior a HDMI para configuraciones multi-monitor o altas frecuencias de actualizacion. DP 2.0 alcanza 80 Gbps. Orientado al mercado de PCs.

VGA (Video Graphics Array)

Conector analogo azul trapezoidal con 15 pines en 3 filas. Solo transmite video (sin audio). Senal analogica que degrada con cables largos. Reemplazado por HDMI y DisplayPort.

DVI (Digital Visual Interface)

Conector blanco con senal digital, mejor calidad que VGA. No transmite audio. Varias variantes: DVI-D (solo digital), DVI-A (solo analogo), DVI-I (ambos). Siendo reemplazado por HDMI/DP.

Puertos de Red, Audio y Serial
RJ-45 · RJ-11 · Jack 3.5mm · Thunderbolt · PS/2 · RS-232
▼

RJ-45 (Ethernet)

Conector de red con 8 pines. Interfaz fisica comunmente usada para conectar redes de cableado estructurado. Categorias 5/5e/6/6a/7/8. Proporciona conexion estable de alta velocidad (10/100/1000/10000 Mbps).

RJ-11 (Telefono)

Conector mas pequeno que el RJ-45. 6 posiciones pero solo 2 o 4 pines activos. Usado para lineas telefonicas analogicas, modems ADSL y faxes. El cable modem DSL usa este conector.

Jack 3.5mm (Audio)

Conector de audio analogico. Verde: auriculares/salida. Rosa/celeste: entrada de microfono. Azul: linea-in. Estandar universal para auriculares y parlantes. Existe version combinada (headset) con 4 polos (TRRS).

Thunderbolt

Tecnologia de Intel que usa conector Mini DisplayPort o USB-C. Hasta 40 Gbps (TB4). Permite conexion en cadena de multiples dispositivos, GPUs externas y monitores. Confundido con USB-C pero con mayor rendimiento.

PS/2

Conector circular de 6 pines. Morado = teclado, Verde = raton. No son intercambiables. Soporta N-Key Rollover completo. Aun usado en teclados gaming y servidores por su fiabilidad.

RS-232 (Serial)

Puerto serial de 9 pines para configurar routers, switches, UPS y equipos industriales via consola serial. Aun presente en servidores. Adaptadores USB-to-Serial muy usados por tecnicos.

Otros Puertos y Slots
LPT · FireWire · eSATA · RCA · BNC · M.2 · SATA · PCIe
▼

LPT (Paralelo)

Puerto paralelo de 25 pines (DB-25). Usado historicamente para impresoras (centronics) y escaneres. Estandar IEEE 1284. Practicamente obsoleto, reemplazado por USB.

FireWire (IEEE 1394)

Conocido tambien como i.Link. Puertos de 4 u 8 pines. Velocidades de 400-800 Mbps. Popular en camaras de video y discos externos. Reemplazado por USB 3.0 y Thunderbolt.

eSATA

Version externa de SATA para discos duros externos de alta velocidad. Hasta 6 Gbps. Raramente usado hoy, reemplazado por USB 3.x y Thunderbolt.

RCA

Conectores coaxiales de color: Amarillo (video composite), Blanco/Rojo (audio estereo analogico). Usado en equipos de audio/video legacy, consolas retro y sistemas de CCTV.

BNC

Conector coaxial de conexion rapida por bayoneta (un cuarto de vuelta). Usado en redes Ethernet 10BASE2 y equipos de video profesional/CCTV.

M.2

Slot compacto en la placa base para SSDs NVMe (hasta 14 GB/s) y modulos WiFi. Clave M (NVMe) o clave B (SATA). Estandar actual de almacenamiento interno de alta velocidad.

SATA

Puerto de datos serial para discos duros y SSDs de 2.5". SATA III: hasta 6 Gbps (~550 MB/s real). Conector L-shaped para datos y cable de alimentacion de 15 pines.

Slots PCIe

Slots de expansion en la placa base: x1, x4, x8, x16. Usados para GPU (x16), tarjetas de red (x1), NVMe adaptadores (x4). PCIe 5.0: 64 GB/s en x16.

USB frontalConectado internamente a un header USB 2.0 (9 pines) o USB 3.0 (19 pines) de la placa base.
Audio frontalConectado al header HD Audio de la placa base (estandar Intel HD Audio).
Cuidado con la polaridad Los LEDs (Power LED y HDD LED) tienen polaridad — el cable de color es positivo. Power SW y Reset SW no tienen polaridad: pueden invertirse sin problema. Consultar el manual de la placa base para la ubicacion de cada pin.
Flujo de Aire (Airflow)
Intake vs Exhaust · Presion positiva/negativa
▼

El flujo de aire dentro del gabinete sigue el principio de que el aire frio entra por la parte baja/frontal y el aire caliente sube y sale por arriba/atras.

Intake (Entrada de aire)

Ventiladores frontales e inferiores que succionan aire fresco hacia el interior. Generalmente montados en la parte frontal del gabinete apuntando hacia adentro.

Exhaust (Salida de aire)

Ventiladores traseros y superiores que expulsan el aire caliente. El ventilador trasero es el mas comun (120mm estandar). Los superiores son ideales para refrigeracion liquida.

Presion positivaMas ventiladores de entrada que salida. El aire solo entra por filtros — menos polvo.Mayor vida util, menos limpieza
Presion negativaMas ventiladores de salida que entrada. El aire entra por todas las ranuras — mas polvo.Mejor refrigeracion de CPU/GPU
EquilibradaIgual numero de intake y exhaust. Balance entre polvo y refrigeracion.La mas comun
Cable Management
Gestion de cables · bridas · espacio trasero
▼

La gestion de cables tiene impacto real mas alla de la estetica:

Flujo de aire

Cables sueltos en la camara principal bloquean el paso del aire entre el front intake y el rear exhaust — puede subir temperaturas 5-10 grados C.

Mantenimiento

Cables bien organizados permiten acceder a los componentes y limpiarlos sin desmontar todo. Facilita el diagnostico de problemas.

Bahias de Almacenamiento
Bahia 3.5" · Bahia 2.5" · Slot M.2
▼

Bahia 3.5"

Para HDDs de escritorio. Generalmente en el fondo del gabinete con rieles deslizantes. Los HDDs de 2.5" tambien caben con adaptadores.

Bahia 2.5"

Para SSDs SATA. Suelen estar en la parte trasera del tray de la placa base para ocultar los cables SATA.

Slot M.2

No es una bahia independiente — el SSD M.2 se instala directamente en la placa base (slot M.2), no en el gabinete. Velocidades de hasta 14 GB/s con NVMe PCIe Gen4.

Bandeja modular

Muchos gabinetes modernos tienen bahias desmontables — si no usas HDDs, se pueden retirar para mejorar el flujo de aire frontal.

Conceptos Clave

BIOS/UEFI · Overclocking · Undervolting · XMP/EXPO · POST · CMOS

BIOS / UEFI
Basic Input Output System · firmware de arranque
▼

La BIOS (Basic Input Output System) identifica componentes del equipo (CPU, RAM, almacenamiento, chipset) y los entrega al SO. Se almacena en memoria flash EEPROM; su configuracion en memoria CMOS, alimentada por pila CR-2032 de 3.3V. Fabricantes principales: AMI y AWARD-Phoenix.

Overclocking
Aumento de frecuencia por encima de especificaciones de fabrica
▼

El overclocking consiste en aumentar la frecuencia de reloj de la CPU, GPU o RAM por encima de los valores de fabrica para obtener mayor rendimiento. Requiere buena refrigeracion, una fuente de poder estable y una placa base con opciones de overclocking en la BIOS. Aumenta el consumo electrico y genera mas calor. Puede acortar la vida util del componente.

Undervolting
Reduccion de voltaje para bajar temperaturas sin perder rendimiento
▼

Con Intel XTU o AMD Ryzen Master, reducir el voltaje del CPU un 5-10% puede bajar temperaturas 10-15 grados C sin perdida de rendimiento. Es lo opuesto al overclocking — busca eficiencia termica sin sacrificar velocidad. Muy util en laptops donde la refrigeracion es limitada. Un undervolt excesivo puede causar inestabilidad y cuelgues.

XMP / EXPO
Perfiles de memoria para velocidad optimizada
▼

XMP (Intel XMP) y EXPO (AMD EXPO) son perfiles preconfigurados en los modulos de memoria RAM que permiten que funcione a su velocidad anunciada. Sin activar el perfil, la RAM corre a la velocidad estandar JEDEC (mas lenta).

PerfilPlataformaUbicacion en BIOS
XMP (Extreme Memory Profile)IntelAI Tweaker / Extreme Tweaker
EXPO (Extended Profiles for OC)AMDEXPO / Memory Context Restore
Latencia real = (CAS / Frecuencia) x 2000 Una DDR4-3200 CL16 tiene la misma latencia real que una DDR4-3600 CL18 (~10ns). DDR4 y DDR5 NO son fisicamente compatibles.
POST (Power-On Self-Test)
Diagnostico de hardware al encender · pitidos de error
▼

El POST es la primera accion que ejecuta la BIOS al encender el equipo: verifica que el CPU, RAM, tarjeta de video, teclado y demas componentes criticos esten presentes y funcionando. Si detecta un error, emite pitidos o muestra un codigo en la placa (Debug LED).

CMOS (Complementary Metal-Oxide Semiconductor)
Memoria de configuracion · pila CR-2032 · reset CMOS
▼

La memoria CMOS almacena la configuracion de la BIOS (hora, fecha, orden de arranque, ajustes de overclocking, etc.). Se mantiene activa por una pila de litio CR-2032 de 3.3V mientras el PC esta apagado.

Reset CMOS — dos metodos

Metodo 1: Pila CR-2032

Retirar la pila durante ~10 segundos usando utensilio de plastico (nunca metalico). Siempre desconectar el cable de corriente antes. La BIOS pierde toda su configuracion.

Metodo 2: Jumper CLRCMOS

Puentear el jumper CLRCMOS en la placa (3 pines: mover de 1-2 a 2-3, esperar 10 segundos, regresar). Tambien requiere apagar el equipo antes.

Cuando cambiar la pila CMOS Si el sistema muestra "CMOS Checksum Invalid" o pierde la hora/fecha constantemente, la pila esta agotada y necesita ser reemplazada por una CR-2032 nueva.
