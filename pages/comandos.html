Linux / Bash — Administración del sistema
Hardware · procesos · systemd · paquetes · usuarios · archivos
▼
bash · comandos esenciales de administración
# ── SISTEMA Y HARDWARE ──
$ uname -a              # Info del kernel
$ lscpu                 # CPU detallada
$ free -h              # RAM y swap
$ df -h               # Uso de discos montados
$ lsblk                # Dispositivos de bloque
$ lspci                # Dispositivos PCI (GPU, etc.)
$ lsusb                # Dispositivos USB
$ dmidecode -t memory  # Info física RAM (sudo)

# ── PROCESOS ──
$ top                  # Monitor interactivo
$ htop                 # top mejorado (apt install htop)
$ ps aux              # Todos los procesos
$ ps aux | grep nginx  # Filtrar proceso
$ kill -9 1234         # Matar PID (forzado)
$ killall firefox      # Matar por nombre

# ── SERVICIOS (systemd) ──
$ systemctl status nginx
$ systemctl start|stop|restart|reload nginx
$ systemctl enable|disable nginx
$ journalctl -u nginx -n 50
$ journalctl -xe          # Logs de error recientes

# ── PAQUETES (APT — Debian/Ubuntu) ──
$ sudo apt update && sudo apt upgrade -y
$ sudo apt install htop
$ sudo apt remove htop
$ sudo apt purge htop   # Borrar también config

# ── USUARIOS Y PERMISOS ──
$ sudo useradd -m newuser
$ sudo passwd newuser
$ sudo usermod -aG sudo user
$ chmod 755 archivo.sh
$ chown user:grupo archivo

# ── ARCHIVOS Y LOGS ──
$ find / -name "*.conf" -type f
$ grep -r "error" /var/log/
$ tar -czf backup.tar.gz /datos
$ tar -xzf backup.tar.gz
$ du -sh /var/log/*
$ tail -f /var/log/syslog    # Log en tiempo real

# ── RED ──
$ ip a                      # Interfaces y direcciones IP
$ ip route                  # Tabla de enrutamiento
$ ip addr add 192.168.1.50/24 dev eth0  # IP estatica temporal
$ ss -tulpn                 # Puertos en escucha
$ nmcli dev status          # Estado de conexiones (NetworkManager)
$ nmtui                     # Interfaz grafica de red en terminal
$ ssh usuario@ip            # Conexion SSH remota
$ rsync -av dir/ usuario@ip:/destino  # Sincronizar carpetas por red

# ── DISCOS Y PARTICIONES ──
$ lsblk -f                   # Discos con sistema de archivos
$ sudo fdisk -l             # Listar discos y particiones
$ sudo blkid                # UUID de particiones (para fstab)
$ df -h                     # Espacio libre por montaje
$ mount /dev/sdb1 /mnt/usb  # Montar una particion
$ umount /mnt/usb          # Desmontar
$ sudo smartctl -a /dev/sda # Salud del disco (SMART)

# ── PAQUETES (otros gestores) ──
$ sudo dnf install htop    # Fedora / RHEL
$ sudo pacman -S htop      # Arch / Manjaro
$ sudo yay -S paquete      # AUR (Arch)
$ flatpak install flathub org.videolan.VLC  # Apps universales Flatpak
$ snap install htop        # Snap (Ubuntu)

# ── BUSQUEDA Y TEXTO ──
$ grep -n "error" archivo.log  # Buscar con numero de linea
$ awk '{print $1}' archivo  # Imprimir primera columna
$ sed 's/antiguo/nuevo/g' archivo  # Reemplazar texto
$ wc -l archivo            # Contar lineas

Comandos de Red

ping · ipconfig · tracert
# PING — conectividad y latencia
> ping 8.8.8.8                  # Ping basico (4 pings en Windows)
> ping -t google.com           # Ping continuo (Ctrl+C para detener)
> ping -n 10 google.com        # 10 pings Windows
$ ping -c 10 google.com        # 10 pings Linux/macOS
# TTL=64 → Linux/macOS  |  TTL=128 → Windows
# Latencia ideal: <10ms LAN · <50ms ISP · <150ms internet
# Request timeout → host bloqueado o inaccesible

# IPCONFIG — configuracion de red Windows
> ipconfig                  # Ver IPs y adaptadores
> ipconfig /all            # MAC, DHCP, DNS servers
> ipconfig /release        # Liberar IP de DHCP
> ipconfig /renew          # Solicitar nueva IP al DHCP
> ipconfig /flushdns       # Limpiar cache DNS local
$ ip addr                   # Linux: equivalente a ipconfig
$ ip route show            # Tabla de enrutamiento Linux

# TRACERT — ruta de paquetes
> tracert google.com         # Windows: muestra cada salto (hop)
> tracert -d google.com     # Sin resolucion DNS (mas rapido)
$ traceroute google.com     # Linux/macOS
$ mtr google.com            # ping + traceroute en tiempo real
# * * * = router no responde ICMP (no siempre indica fallo)
nslookup · netstat · arp · wifi · reset
# NSLOOKUP / DIG — consultas DNS
> nslookup google.com           # Consulta DNS por defecto
> nslookup google.com 8.8.8.8   # Usar DNS de Google
> nslookup -type=MX gmail.com   # Registros de correo
$ dig +short google.com         # Solo la IP resultante
$ dig -x 8.8.8.8               # Reverse DNS lookup

# NETSTAT — conexiones y puertos
> netstat -ano                  # Conexiones con PID
> netstat -ano | findstr :80   # Proceso usando el puerto 80
> netstat -a                    # Ver si hay virus/malware por conexiones inusuales
$ ss -tulpn                    # Linux: puertos en escucha con proceso

# ARP — tabla de direcciones MAC
> arp -a                       # Ver tabla ARP (IP → MAC)
> arp -d 192.168.1.100         # Eliminar entrada ARP

# WIFI Y RESET DE PILA DE RED
> netsh wlan show profiles           # Redes WiFi guardadas
> netsh wlan show profile name="MiRed" key=clear  # Ver contrasena
> netsh interface ip reset           # Resetear TCP/IP stack
> netsh winsock reset               # Resetear Winsock (problemas de conexion)

# NMAP — escaneo de red (instalar por separado)
          $ nmap -sn 192.168.1.0/24       # Ping scan: hosts activos en la red
          $ nmap -sV 192.168.1.1          # Detectar servicios y versiones

# CURL — pruebas HTTP (cliente de red)
> curl -I https://google.com       # Solo headers HTTP (status code)
> curl -v https://mi-sitio.com      # Detallado: TLS, DNS, handshake
$ curl -s ifconfig.me               # IP publica actual

# HOSTNAME / DOMINIO / IP
> hostname                    # Nombre del equipo
> whoami                      # Usuario actual
$ hostname -I                  # IPs locales Linux

# TROUBLESHOOTING AVANZADO
> pathping google.com           # tracert + estadisticas de perdida
> getmac /v                    # Direcciones MAC del equipo
> netsh interface show interface  # Estado de adaptadores
$ ip neigh                    # Tabla ARP en Linux (vecinos)
$ ethtool eth0                  # Estado y velocidad del enlace
🔍
Flujo de solucion de problemas de conectividad ① Deshabilitar y rehabilitar la placa de red en Centro de Redes. ② ipconfig /release + /renew + /flushdns. ③ Apagar y reiniciar el router/modem. ④ Probar el cable de red con un tester de red. ⑤ Conectar el modem directamente a la PC para descartar router. ⑥ Cambiar entre Ethernet y WiFi para descartar placa de red. ⑦ Si persiste, contactar al ISP ya que la falla puede estar en el DSLAM de la central telefonica.
