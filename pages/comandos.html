Abrir Programas desde CMD y Run (start)
Word · Excel · navegadores · herramientas del sistema
▼

El comando start lanza un programa en una ventana separada sin bloquear la consola. Estos mismos nombres se pueden escribir directamente en el cuadro Win+R (Ejecutar) sin necesidad de usar start.

start outlookMicrosoft Outlook
start onenoteMicrosoft OneNote

start notepadBloc de notas
start mspaintPaint
start calcCalculadora
start cmdNueva ventana de CMD
start powershellPowerShell
start wtWindows Terminal
start taskmgrAdministrador de tareas
start explorerExplorador de archivos
start winverVersión de Windows instalada
start devmgmt.mscAdministrador de dispositivos

cmd · ejemplos de uso de start
# Abrir Word, Excel o PowerPoint
> start winword
> start excel
> start powerpnt

# Si el programa no está en el PATH, usar la ruta completa
# (las comillas vacías "" son el título de la ventana, evita errores)
> start "" "C:\Program Files\Microsoft Office\root\Office16\WINWORD.EXE"

# Abrir una carpeta en el Explorador de archivos
> start "C:\Users\Public\Documentos"

# Abrir una URL en el navegador por defecto
> start https://www.example.com

# Abrir una aplicación de Microsoft Store
> start ms-windows-store://home
💡
Atajo de oro: pulsa Win+R y escribe el nombre del programa (ej. winword, calc, devmgmt.msc) sin el start; se abre al instante. Es el metodo más rápido para lanzar herramientas del sistema como msconfig, control o compmgmt.msc.

Ver todos los Programas Instalados
Inventario de software · búsqueda · exportación
▼

Para conocer qué software tiene una PC (ideal antes de un formateo o en un diagnóstico), consulta el registro de desinstalación o usa wmic en CMD y Get-ItemProperty en PowerShell.

cmd · listar programas instalados
# Listar todos los programas con nombre y versión (puede tardar)
> wmic product get name,version

# Buscar un programa por nombre
> wmic product where "name like '%chrome%'" get name,version

# Exportar el inventario a un archivo de texto
> wmic product get name,version,installdate > programas.txt

# Alternativa rápida: leer las claves del registro de desinstalación
> reg query "HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall" /s | findstr /i "DisplayName"
powershell · listar programas con el registro
# Listar programas instalados (64 bits) ordenados por nombre
> Get-ItemProperty "HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*" |
    Where-Object $_.DisplayName |
    Select-Object DisplayName, DisplayVersion, Publisher |
    Sort-Object DisplayName | Format-Table -AutoSize

# Incluir programas de 32 bits (Wow6432Node) y del usuario actual (HKCU)
> Get-ItemProperty "HKLM:\Software\Wow6432Node\Microsoft\Windows\CurrentVersion\Uninstall\*",
    "HKCU:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*" |
    Where-Object $_.DisplayName | Select-Object DisplayName, DisplayVersion

# Buscar un programa específico
> Get-ItemProperty "HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*" |
    Where-Object $_.DisplayName -like "*chrome*"

# Aplicaciones de Microsoft Store
> Get-AppxPackage | Select-Object Name, Version

# Alternativa con PackageManagement (Get-Package)
> Get-Package | Where-Object ProviderName -eq "Programs" | Select-Object Name, Version
⚠️
wmic está obsoleto: Microsoft lo retiró de Windows 11 24H2. Si wmic no existe en el equipo, usa las alternativas de PowerShell. Las claves HKCU\... solo listan programas instalados por el usuario actual; algunas apps (ej. UWP/Store) no aparecen en estas claves.

Linux / Bash — Administración del sistema
Hardware · procesos · systemd · paquetes · usuarios · archivos
▼
bash · comandos esenciales de administración
# ── SISTEMA Y HARDWARE ──
$ uname -a              # Info del kernel
$ lscpu                 # CPU detallada
$ free -h              # RAM y swap
$ df -h               # Uso de discos montados
$ lsblk                # Dispositivos de bloque
$ lspci                # Dispositivos PCI (GPU, etc.)
$ lsusb                # Dispositivos USB
$ dmidecode -t memory  # Info física RAM (sudo)

# ── PROCESOS ──
$ top                  # Monitor interactivo
$ htop                 # top mejorado (apt install htop)
$ ps aux              # Todos los procesos
$ ps aux | grep nginx  # Filtrar proceso
$ kill -9 1234         # Matar PID (forzado)
$ killall firefox      # Matar por nombre

# ── SERVICIOS (systemd) ──
$ systemctl status nginx
$ systemctl start|stop|restart|reload nginx
$ systemctl enable|disable nginx
$ journalctl -u nginx -n 50
$ journalctl -xe          # Logs de error recientes

# ── PAQUETES (APT — Debian/Ubuntu) ──
$ sudo apt update && sudo apt upgrade -y
$ sudo apt install htop
$ sudo apt remove htop
$ sudo apt purge htop   # Borrar también config

# ── USUARIOS Y PERMISOS ──
$ sudo useradd -m newuser
$ sudo passwd newuser
$ sudo usermod -aG sudo user
$ chmod 755 archivo.sh
$ chown user:grupo archivo

# ── ARCHIVOS Y LOGS ──
$ find / -name "*.conf" -type f
$ grep -r "error" /var/log/
$ tar -czf backup.tar.gz /datos
$ tar -xzf backup.tar.gz
$ du -sh /var/log/*
$ tail -f /var/log/syslog    # Log en tiempo real

# ── RED ──
$ ip a                      # Interfaces y direcciones IP
$ ip route                  # Tabla de enrutamiento
$ ip addr add 192.168.1.50/24 dev eth0  # IP estatica temporal
$ ss -tulpn                 # Puertos en escucha
$ nmcli dev status          # Estado de conexiones (NetworkManager)
$ nmtui                     # Interfaz grafica de red en terminal
$ ssh usuario@ip            # Conexion SSH remota
$ rsync -av dir/ usuario@ip:/destino  # Sincronizar carpetas por red

# ── DISCOS Y PARTICIONES ──
$ lsblk -f                   # Discos con sistema de archivos
$ sudo fdisk -l             # Listar discos y particiones
$ sudo blkid                # UUID de particiones (para fstab)
$ df -h                     # Espacio libre por montaje
$ mount /dev/sdb1 /mnt/usb  # Montar una particion
$ umount /mnt/usb          # Desmontar
$ sudo smartctl -a /dev/sda # Salud del disco (SMART)

# ── PAQUETES (otros gestores) ──
$ sudo dnf install htop    # Fedora / RHEL
$ sudo pacman -S htop      # Arch / Manjaro
$ sudo yay -S paquete      # AUR (Arch)
$ flatpak install flathub org.videolan.VLC  # Apps universales Flatpak
$ snap install htop        # Snap (Ubuntu)

# ── BUSQUEDA Y TEXTO ──
$ grep -n "error" archivo.log  # Buscar con numero de linea
$ awk '{print $1}' archivo  # Imprimir primera columna
$ sed 's/antiguo/nuevo/g' archivo  # Reemplazar texto
$ wc -l archivo            # Contar lineas

Comandos de Red

ping · ipconfig · tracert
# PING — conectividad y latencia
> ping 8.8.8.8                  # Ping basico (4 pings en Windows)
> ping -t google.com           # Ping continuo (Ctrl+C para detener)
> ping -n 10 google.com        # 10 pings Windows
$ ping -c 10 google.com        # 10 pings Linux/macOS
# TTL=64 → Linux/macOS  |  TTL=128 → Windows
# Latencia ideal: <10ms LAN · <50ms ISP · <150ms internet
# Request timeout → host bloqueado o inaccesible

# IPCONFIG — configuracion de red Windows
> ipconfig                  # Ver IPs y adaptadores
> ipconfig /all            # MAC, DHCP, DNS servers
> ipconfig /release        # Liberar IP de DHCP
> ipconfig /renew          # Solicitar nueva IP al DHCP
> ipconfig /flushdns       # Limpiar cache DNS local
$ ip addr                   # Linux: equivalente a ipconfig
$ ip route show            # Tabla de enrutamiento Linux

# TRACERT — ruta de paquetes
> tracert google.com         # Windows: muestra cada salto (hop)
> tracert -d google.com     # Sin resolucion DNS (mas rapido)
$ traceroute google.com     # Linux/macOS
$ mtr google.com            # ping + traceroute en tiempo real
# * * * = router no responde ICMP (no siempre indica fallo)
nslookup · netstat · arp · wifi · reset
# NSLOOKUP / DIG — consultas DNS
> nslookup google.com           # Consulta DNS por defecto
> nslookup google.com 8.8.8.8   # Usar DNS de Google
> nslookup -type=MX gmail.com   # Registros de correo
$ dig +short google.com         # Solo la IP resultante
$ dig -x 8.8.8.8               # Reverse DNS lookup

# NETSTAT — conexiones y puertos
> netstat -ano                  # Conexiones con PID
> netstat -ano | findstr :80   # Proceso usando el puerto 80
> netstat -a                    # Ver si hay virus/malware por conexiones inusuales
$ ss -tulpn                    # Linux: puertos en escucha con proceso

# ARP — tabla de direcciones MAC
> arp -a                       # Ver tabla ARP (IP → MAC)
> arp -d 192.168.1.100         # Eliminar entrada ARP

# WIFI Y RESET DE PILA DE RED
> netsh wlan show profiles           # Redes WiFi guardadas
> netsh wlan show profile name="MiRed" key=clear  # Ver contrasena
> netsh interface ip reset           # Resetear TCP/IP stack
> netsh winsock reset               # Resetear Winsock (problemas de conexion)

# NMAP — escaneo de red (instalar por separado)
          $ nmap -sn 192.168.1.0/24       # Ping scan: hosts activos en la red
          $ nmap -sV 192.168.1.1          # Detectar servicios y versiones

# CURL — pruebas HTTP (cliente de red)
> curl -I https://google.com       # Solo headers HTTP (status code)
> curl -v https://mi-sitio.com      # Detallado: TLS, DNS, handshake
$ curl -s ifconfig.me               # IP publica actual

# HOSTNAME / DOMINIO / IP
> hostname                    # Nombre del equipo
> whoami                      # Usuario actual
$ hostname -I                  # IPs locales Linux

# TROUBLESHOOTING AVANZADO
> pathping google.com           # tracert + estadisticas de perdida
> getmac /v                    # Direcciones MAC del equipo
> netsh interface show interface  # Estado de adaptadores
$ ip neigh                    # Tabla ARP en Linux (vecinos)
$ ethtool eth0                  # Estado y velocidad del enlace
🔍
Flujo de solucion de problemas de conectividad ① Deshabilitar y rehabilitar la placa de red en Centro de Redes. ② ipconfig /release + /renew + /flushdns. ③ Apagar y reiniciar el router/modem. ④ Probar el cable de red con un tester de red. ⑤ Conectar el modem directamente a la PC para descartar router. ⑥ Cambiar entre Ethernet y WiFi para descartar placa de red. ⑦ Si persiste, contactar al ISP ya que la falla puede estar en el DSLAM de la central telefonica.

Administracion Avanzada y Reparacion

Reparacion de Arranque de Windows

Cuando Windows no arranca, el Entorno de Recuperacion (WinRE) ofrece herramientas de linea de comandos para reparar el registro de arranque y el sector de inicio. Accede desde un USB de instalacion: Reparar el equipo > Solucion de problemas > Simbolo del sistema.

cmd · reparacion de arranque desde WinRE
# bootrec: reparar MBR, sector de arranque y BCD
> bootrec /fixmbr
> bootrec /fixboot
> bootrec /rebuildbcd
# Si rebuildbcd no detecta instalaciones, respaldar y recrear el BCD
> bcdedit /export C:\BCD_Backup
> attrib c:\boot\bcd -h -r -s
> ren c:\boot\bcd bcd.old
> bootrec /rebuildbcd
# Alternativa directa: reconstruir el cargador de Windows
> bcdboot C:\Windows

Con bcdedit se consulta y modifica la configuracion de arranque del sistema. Los identificadores entre llaves, como {default}, referencian entradas concretas del BCD.

cmd · bcdedit - ver y editar la configuracion de arranque
# Ver toda la configuracion de arranque
> bcdedit /enum
# Ver solo la entrada del sistema operativo actual
> bcdedit /enum {current}
# Cambiar la descripcion de la entrada por defecto
> bcdedit /set {default} description "Windows 11 Pro"
# Arrancar en modo seguro en el proximo reinicio
> bcdedit /set {default} safeboot minimal
# Quitar el modo seguro
> bcdedit /deletevalue {default} safeboot
# Fijar la particion de arranque
> bcdedit /set {default} device partition=C:
  • msinfo32: Muestra la informacion completa del sistema: hardware, componentes, entorno de software, estado de Secure Boot y TPM. Util para diagnosticar conflictos entre drivers.
  • regedit: Editor del registro de Windows. Permite revisar y modificar claves de inicio de aplicaciones, servicios y politicas.
  • reg export: Respalda el registro antes de tocarlo. Ejemplo: reg export HKLM\SOFTWARE respaldo.reg.
  • sigverif: Verificador de firmas de drivers. Lista archivos del sistema sin firma valida, util para detectar drivers corruptos o no firmados.
Precaucion: antes de modificar el BCD o el registro, exporta un respaldo. Un error de sintaxis en bcdedit o una clave borrada puede impedir que el equipo arranque.
Scripting Batch y PowerShell

El scripting automatiza tareas repetitivas de mantenimiento. Batch (.bat) es el clasico de CMD; PowerShell (.ps1) es mas potente y trabaja con objetos, lo que lo hace ideal para administracion.

  • Variables: Se declaran con set NOMBRE=valor y se leen con %NOMBRE%.
  • if: Condicionales: if %var%==valor (comando) else (comando).
  • for: Bucles sobre listas o archivos: for %%f in (*.txt) do echo %%f (en un .bat usa doble %).
  • %errorlevel%: Codigo de salida del ultimo comando; 0 significa exito, otro valor indica error.
  • start: Lanza un programa en una ventana separada: start notepad.exe.
  • Redireccion: > sobrescribe un archivo y >> agrega al final: ipconfig /all > red.txt.
batch · script de respaldo de documentos
@echo off
set BACKUP=C:\Respaldo
if not exist "%BACKUP%" mkdir "%BACKUP%"
echo Respaldando documentos del usuario...
xcopy "%USERPROFILE%\Documents\*" "%BACKUP%\Documentos" /E /I /Y
if %errorlevel%==0 (
  echo Respaldo completado sin errores.
) else (
  echo Hubo errores en el respaldo.
)
pause
  • Pipelines: Pasan objetos entre cmdlets: Get-Process | Sort-Object CPU -Descending | Select-Object -First 5.
  • Where-Object: Filtra objetos: Get-Service | Where-Object {$_.Status -eq 'Running'}.
  • Select-Object: Elige propiedades: Get-Process | Select-Object Name,CPU.
  • ForEach-Object: Procesa cada elemento de la tuberia: 1..10 | ForEach-Object {$_ * 2}.
  • Funciones: function Resumen-CPU {Get-Process | Sort-Object CPU -Descending}.
  • profile.ps1: Se ejecuta al abrir PowerShell; ahi se definen alias, funciones y variables personales.
  • Execution Policy: Restricted bloquea scripts y RemoteSigned permite scripts locales (recomendado): Set-ExecutionPolicy RemoteSigned.
  • Modulos: Import-Module Nombre carga funcionalidad extra; los de la comunidad se instalan desde PSGallery con Install-Module.
powershell · limpieza de archivos temporales
$tempPaths = @(
  "$env:TEMP",
  "$env:WINDIR\Temp"
)
foreach ($path in $tempPaths) {
  Get-ChildItem -Path $path -Recurse -Force -ErrorAction SilentlyContinue |
    Remove-Item -Recurse -Force -ErrorAction SilentlyContinue
}
Write-Host "Temporales limpiados." -ForegroundColor Green
Administracion Remota

La administracion remota permite gestionar equipos de la red sin estar fisicamente frente a ellos. Son herramientas imprescindibles para soporte tecnico y servidores.

  • psexec \\equipo comando: Ejecuta comandos en un equipo remoto (Sysinternals). Ejemplo: psexec \\PC-OFICINA ipconfig.
  • winrm quickconfig: Configura WinRM en el equipo para habilitar la administracion remota de PowerShell.
  • Enter-PSSession / Invoke-Command: Abren una sesion interactiva o ejecutan un comando puntual: Invoke-Command -ComputerName PC-OFICINA {Get-Service}.
  • mstsc: Cliente de escritorio remoto (RDP) de Windows.
  • net use \\equipo\share: Mapea un recurso compartido a una letra de unidad: net use Z: \\servidor\documentos.
  • net view: Lista los equipos y recursos compartidos visibles en la red.
  • net share: Administra los recursos compartidos locales del equipo.
  • sc \\equipo config servicio: Cambia la configuracion de un servicio remoto: sc \\PC-OFICINA config spooler start= auto.

Linux Avanzado

Para administracion avanzada, Linux ofrece herramientas de diagnostico profundo, control fino de procesos y seguridad a nivel de kernel.

  • lsof: Lista archivos abiertos por procesos. lsof -i :80 muestra que proceso usa el puerto 80.
  • strace: Rastrea las llamadas al sistema de un proceso; ideal para depurar fallos de inicio de aplicaciones.
  • iptables / ufw: Firewall del kernel. ufw enable y ufw allow ssh bastan para asegurar un servidor simple.
  • cron y systemd timers: Programan tareas: crontab -e para cron y systemctl list-timers para timers de systemd.
  • nice / renice: Ajustan la prioridad de los procesos: renice -n -5 -p 1234.
  • timeout: Limita el tiempo de ejecucion: timeout 60 comando.
  • tmux / screen: Multiplexores de terminal que mantienen sesiones vivas al cerrar la conexion SSH.
  • nproc: Muestra el numero de nucleos disponibles del CPU.
  • setfacl: Permisos ACL granulares por usuario: setfacl -m u:user:rw archivo.
  • SELinux / AppArmor: Control de acceso obligatorio. getenforce y sestatus muestran el estado en distribuciones basadas en RHEL/Fedora.
  • ss -tulpn: Puertos en escucha con el proceso asociado; version moderna de netstat.

Windows Terminal y Productividad de Consola

Windows Terminal es la aplicacion de consola moderna de Microsoft. Unifica CMD, PowerShell, WSL y Azure Cloud Shell en pestanas con color, fuentes, paneles divididos y perfiles personalizables.

  • Ctrl+Shift+T: Abrir una nueva pestana.
  • Ctrl+Shift+W: Cerrar la pestana actual.
  • Ctrl+Shift+D: Duplicar el panel actual en una pestana nueva.
  • Alt+Shift+- / Alt+Shift+=: Dividir el panel en horizontal o vertical.
  • Ctrl+Shift+1..9: Cambiar rapidamente entre pestanas.
  • Ctrl+Scroll: Ajustar el tamano de la fuente sobre la marcha.
wt · linea de comandos de windows terminal
# Abrir en un directorio con una pestana de Ubuntu
> wt -d C:\Users --tab -p "Ubuntu"
# Dividir el panel con PowerShell y CMD
> wt -p "PowerShell" -p "Command Prompt" --tab
# Maximizar con varias pestanas al iniciar
> wt --maximized nt -p "Ubuntu" nt -p "PowerShell"
  • Perfiles: Cada shell instalado aparece como perfil en el menu de pestanas; se configura fuente, esquema de color, transparencia y directorio de inicio.
  • Configuracion JSON: Los ajustes viven en settings.json, editable desde el menu (Ctrl+,) o con la linea de comandos wt -s.
  • Importar / Exportar: Copiando el settings.json se porta toda la configuracion a otro equipo sin reinstalar nada.
  • Modo quake: La combinacion Win+` despliega Windows Terminal como una terminal desplegable sobre cualquier ventana, el truco favorito de los tecnicos.
Tip: el modo quake (Win+`) da acceso instantaneo a la consola sin romper el flujo de trabajo; ideal para llamadas rapidas de diagnostico.
