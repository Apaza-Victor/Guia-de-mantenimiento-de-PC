Terminos de Hardware — A a G

// Componentes, firmware y conceptos basicos

TerminoDefinicion
APUAccelerated Processing Unit — CPU con graficos integrados (AMD)
BCLKBase Clock — frecuencia base del sistema desde la que se multiplican la CPU, RAM y PCIe
BIOSBasic Input Output System — firmware que inicializa el hardware al encender el PC y cede el control al SO
Cache L1/L2/L3Memoria ultrarrapida dentro del CPU; L1 es la mas rapida y pequena, L3 es la mas lenta y grande
ChipsetConjunto de circuitos integrados que controlan la comunicacion entre CPU, RAM, GPU y dispositivos
CMOSComplementary Metal-Oxide Semiconductor — memoria que almacena la configuracion de la BIOS; alimentada por pila CR2032
CPUCentral Processing Unit — el procesador, el "cerebro" del PC que ejecuta las instrucciones
CoreNucleo — unidad de procesamiento independiente dentro del CPU
DieEl chip de silicio fisico dentro de un CPU o GPU
DIMMDual Inline Memory Module — formato de modulo de RAM de escritorio
DriverControlador — software que permite que el SO hable con el hardware
DDR4 / DDR5Generaciones de memoria RAM: mayor velocidad y menor voltaje que la generacion anterior
ECCError-Correcting Code — memoria con deteccion y correccion de errores, usada en servidores
FirmwareSoftware grabado en un chip de hardware (BIOS, UEFI, firmware de SSD)
GPUGraphics Processing Unit — procesador grafico o tarjeta de video
Gigahertz (GHz)Miles de millones de ciclos por segundo — unidad de medida de la velocidad del CPU
AirflowFlujo de aire dentro del gabinete; un buen airflow mantiene frescos CPU, GPU, VRM y discos
BenchmarkPrueba estandarizada que mide el rendimiento de un componente o de todo el sistema
Cuello de botella (Bottleneck)Componente que limita el rendimiento del resto (ej: CPU debil con GPU potente desperdicia su potencial)
Curva de ventiladorPerfil que relaciona temperatura con velocidad del ventilador para equilibrar ruido y refrigeracion
Ventilador (Fan)Componente que mueve aire para enfriar CPU, GPU, gabinete y fuente

// Almacenamiento, energia y firmware moderno

TerminoDefinicion
IHSIntegrated Heat Spreader — cubierta metalica del CPU que distribuye el calor
M.2Formato compacto de tarjeta para SSDs NVMe/SATA y Wi-Fi, montado directo en la placa
NANDTipo de memoria flash usada en SSDs y pendrives
NVMeNon-Volatile Memory Express — protocolo de comunicacion para SSDs via PCIe, mucho mas rapido que SATA
OverclockingAumentar la frecuencia de CPU/RAM/GPU por encima de las especificaciones de fabrica
PCIePeripheral Component Interconnect Express — bus de expansion para GPU, SSDs y tarjetas
POSTPower-On Self Test — verificacion inicial de hardware que realiza la BIOS al encender el PC
PWMPulse Width Modulation — control de velocidad de ventiladores por pulsos
PSUPower Supply Unit — la fuente de alimentacion que convierte AC en DC para el PC
PSU Efficiency (80 Plus)Certificacion de eficiencia energetica: White 80%, Bronze 82%, Gold 87%, Platinum 90%, Titanium 94%
RAIDRedundant Array of Independent Disks — combina multiples discos para obtener redundancia o velocidad
RAMRandom Access Memory — memoria volatil de acceso rapido donde se cargan los programas
SATASerial ATA — interfaz para conectar discos duros, SSDs y unidades opticas a la placa base
SocketZocalo de la placa donde se instala el CPU (LGA, PGA, AM4, AM5, LGA1700)
SSDSolid State Drive — almacenamiento sin partes moviles, mucho mas rapido que un HDD
TDPThermal Design Power — calor maximo que el cooler debe disipar; indica potencia tipica del CPU
UEFIUnified Extensible Firmware Interface — version moderna de la BIOS con interfaz grafica y soporte GPT
USBUniversal Serial Bus — estandar de conexion de perifericos (USB-A, USB-C, 2.0, 3.0, 3.2)
VRMVoltage Regulator Module — circuito en la placa base que regula y estabiliza el voltaje al CPU
XMP / EXPOPerfiles de overclocking de RAM de un toque (Intel XMP, AMD EXPO)
Artefactos GraficosDistorsiones visuales (lineas, pixeles o puntos de colores) que indican falla o sobrecalentamiento de la GPU
dGPUDiscrete GPU — tarjeta grafica dedicada con su propio chip, memoria y disipador
DLSSDeep Learning Super Sampling — tecnologia de NVIDIA que renderiza a menor resolucion y escala con IA para mas FPS
eGPUExternal GPU — tarjeta grafica externa conectada por Thunderbolt para potenciar portatiles
FreeSyncTecnologia de AMD que sincroniza la tasa de refresco del monitor con la GPU para evitar cortes de imagen
FSRFidelityFX Super Resolution — tecnologia de escalado de AMD equivalente a DLSS, abierta y multiplataforma
GDDR6Tipo de memoria grafica rapida usada en las tarjetas de video modernas
G-SyncTecnologia de NVIDIA que sincroniza monitor y GPU para eliminar cortes y retraso de imagen
HDRHigh Dynamic Range — mayor rango de brillo y color en pantallas, videos y juegos compatibles
iGPUIntegrated GPU — graficos integrados dentro del procesador (Intel UHD, AMD Radeon)
Tasa de Refresco (Hz)Veces por segundo que se actualiza la imagen en pantalla (60, 144, 240 Hz); a mayor valor, mas fluidez
Threads / HilosSecuencias de instrucciones que un nucleo puede ejecutar en paralelo (ej: 8 nucleos / 16 hilos)
VRAMVideo RAM — memoria dedicada de la tarjeta grafica donde se guardan texturas y buffers

Terminos de Memoria y Almacenamiento

// RAM, discos, sistemas de archivos y unidades de medida

TerminoDefinicion
BitUnidad minima de informacion: 0 o 1
Byte8 bits — unidad basica de almacenamiento
KB / MB / GB / TBKilobyte, Megabyte, Gigabyte, Terabyte — multiplos de almacenamiento (1024x)
Dual ChannelUsar dos modulos de RAM en paralelo para duplicar el ancho de banda
HDDHard Disk Drive — disco mecanico con platos giratorios y cabezal magnetico
Latencias (RAM)CL (CAS Latency) — retardo en ciclos entre pedido y entrega de datos en la RAM
Memoria VirtualSwap — usa espacio del disco como extension de la RAM cuando esta se agota
NTFS / exFAT / FAT32Sistemas de archivos de Windows; NTFS permite archivos enormes y permisos
ext4Sistema de archivos por defecto en Linux
TRIMComando que mantiene el rendimiento y la vida util de un SSD
Volatil vs No volatilRAM es volatil (pierde datos al apagar); SSD/HDD son no volatiles
mdschedComando de Windows que abre el Diagnostico de Memoria para probar la RAM al reiniciar
Optimizacion de unidadesFuncion de Windows que combina TRIM en SSD o desfragmentacion en HDD segun el tipo de disco
Sobre-provisioningEspacio extra reservado de fabrica en un SSD que reduce el desgaste de las celdas y mantiene el rendimiento

Terminos de Energia y Refrigeracion

// Voltaje, watts, coolers y gestion termica

TerminoDefinicion
Amperio (A)Unidad de corriente electrica que fluye por el circuito
Air CoolerDisipador de torre con aletas y ventilador que enfria el CPU
AIOAll-In-One — refrigeracion liquida con radiador, bomba y bloque en un solo sistema
Custom LoopRefrigeracion liquida a medida con reservorio, bomba, tubos y bloques
HeatpipeTubo de cobre que transporta calor por cambio de fase dentro del disipador
Pasta TermicaCompuesto que mejora la transferencia de calor entre CPU y cooler
RPMRevoluciones por minuto — velocidad del ventilador
UndervoltingReducir el voltaje del CPU/GPU para bajar temperatura y consumo sin perder rendimiento
Voltaje (V)Diferencia de potencial electrico — los CPUs modernos usan ~1.1-1.4V
Watt (W)Unidad de potencia = voltios x amperios; la PSU se elige en watts
Liquid Metal (Metal Liquido)Compuesto termico conductivo a base de galio; rinde mas que la pasta termica pero exige aislar los contactos cercanos
PS_ONPin verde del conector ATX que la placa usa para encender la fuente; la prueba del clip lo puentea para encenderla sin placa
Refrigeracion LiquidaSistema que usa un liquido refrigerante para llevar el calor del componente al radiador, donde el aire lo disipa
Thermal PadsAlmohadillas termicas que transmiten calor entre chips (VRM, NVMe, VRAM) y sus disipadores sin usar pasta

Terminos de Redes y Conectividad

// Protocolos, infraestructura y conceptos de Internet

TerminoDefinicion
DHCPAsigna direcciones IP automaticamente a los dispositivos de la red
DNSTraduce nombres de dominio (google.com) a direcciones IP numericas
EthernetEstandar de redes cableadas con conectores RJ-45 y cables UTP
FirewallBarrera de seguridad que filtra el trafico entrante y saliente de la red
GatewayPuerta de enlace — dispositivo (generalmente el router) que conecta tu red a Internet
IP Publica / PrivadaPublica: visible en Internet. Privada: solo dentro de tu red local (192.168.x.x)
IPv4 / IPv6Versiones del protocolo IP: IPv4 usa 32 bits (192.168.1.1), IPv6 usa 128 bits
LAN / WANLocal Area Network (red local) / Wide Area Network (red extensa, como Internet)
Latencia / PingTiempo en ms que tarda un dato en ir y volver — importante en juegos online
MAC AddressDireccion fisica unica de la tarjeta de red (ej: 00:1A:2B:3C:4D:5E)
Mbps / GbpsMegabits y gigabits por segundo — velocidad de transferencia de red
NATNetwork Address Translation — permite que multiples dispositivos compartan una IP publica
RouterDispositivo que enruta el trafico entre redes y reparte la conexion a Internet
Subred / MascaraDivision de una red IP; la mascara define cuantos dispositivos caben (255.255.255.0 = /24)
SwitchDispositivo que conecta multiples equipos dentro de la misma red local
TCP / UDPProtocolos de transporte: TCP fiable y ordenado, UDP rapido sin confirmacion
VPNRed Privada Virtual — cifra tu trafico y oculta tu IP real
Wi-FiTecnologia de red inalambrica (802.11 a/b/g/n/ac/ax)
802.1XEstandar de autenticacion de puertos usado en redes empresariales y Wi-Fi corporativo
Access Point (AP)Dispositivo que emite la senal Wi-Fi y conecta los clientes inalambricos a la red cableada
APIPAAutomatic Private IP Addressing — Windows asigna 169.254.x.x cuando no encuentra un servidor DHCP
BGPBorder Gateway Protocol — protocolo de enrutamiento que conecta entre si los sistemas autonomes de Internet
DMZZona desmilitarizada — host expuesto a Internet con todos los puertos abiertos, usado por ejemplo para consolas
FTTHFiber To The Home — fibra optica que llega directamente hasta el hogar del cliente
IDSIntrusion Detection System — vigila el trafico de red y alerta sobre actividad sospechosa
IPSIntrusion Prevention System — detecta las amenazas y ademas las bloquea activamente
Mesh Wi-FiSistema de varios nodos que reparten una sola red Wi-Fi sin cortes por toda la casa
MPLSMultiprotocol Label Switching — tecnologia de transporte que enruta paquetes por etiquetas en redes de proveedores
ONTOptical Network Terminal — el modem que convierte la senal de fibra optica en Ethernet para tu router
OSPFOpen Shortest Path First — protocolo de enrutamiento interno que calcula la ruta mas corta hasta el destino
PoEPower over Ethernet — alimenta dispositivos como camaras y Access Points por el mismo cable de red
QoSQuality of Service — prioriza el trafico importante (juegos, videollamadas) sobre el resto de la red
RADIUSServidor central de autenticacion para redes 802.1X, Wi-Fi empresarial y VPN
RIPRouting Information Protocol — protocolo de enrutamiento sencillo por saltos, apto para redes pequenas
SFPSmall Form-factor Pluggable — modulo intercambiable de fibra o cobre para switches y routers
SubnettingTecnica de dividir una red en subredes mas pequenas para ordenar y optimizar el direccionamiento IP
VLANVirtual LAN — separa logicamente dispositivos dentro del mismo switch aunque compartan el cableado
VLSMVariable Length Subnet Mask — subnetting con mascaras de longitud variable para no desperdiciar direcciones

// Sistemas operativos, malware y proteccion

TerminoDefinicion

BackupCopia de seguridad de tus datos en otro disco o servicio
KernelNucleo del sistema operativo que gestiona el hardware y los procesos

TroyanoMalware disfrazado de programa legitimo para infectar el sistema
VirusMalware que se propaga infectando archivos y programas
Administrador de dispositivosHerramienta de Windows para ver y gestionar el hardware y sus drivers

SuspensionEstado de bajo consumo que pausa el sistema; mantiene la RAM activa para reanudar al instante
TPMTrusted Platform Module — chip que guarda claves criptograficas y respalda BitLocker y Windows Hello
Visor de eventosHerramienta de Windows que registra errores y avisos del sistema para diagnosticar fallas
