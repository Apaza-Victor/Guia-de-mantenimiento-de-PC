PCPartPicker

Hardware

Herramienta para compatibilidad de componentes, comparar precios y armar configuraciones de PC virtualmente.

pcpartpicker.com

Tom's Hardware

Hardware

Reviews detalladas, benchmarks y guias de hardware. Una de las fuentes mas confiables del mundo.

tomshardware.com

NetworkCalc

Redes

Calculadora de subredes CIDR. Calcula rangos de IPs, mascaras y numero de hosts automaticamente.

networkcalc.com

SubnetMask.com

Redes

Calculadora de subredes con visualizacion grafica de rangos IP, broadcast y hosts disponibles.

subnetmask.com

TechPowerUp

Hardware

Reviews de GPU, CPU y perifericos. Base de datos de especificaciones de tarjetas graficas muy completa.

techpowerup.com

Wireshark

Redes

Analizador de protocolos de red (packet sniffer). Indispensable para diagnostico y aprendizaje de redes.

wireshark.org

PassMark

Hardware

Benchmarks de CPU, GPU, discos y RAM. Comparativa entre cientos de modelos con graficos detallados.

passmark.com

MemTest86

Diagnostico

El estandar para testeo de memoria RAM. Version gratuita y pagada. Se ejecuta desde USB booteable.

memtest86.com

Cisco Networking Academy

Certificacion

Cursos oficiales de redes, seguridad y programacion de Cisco. Certificaciones CCNA, CCNP y mas.

netacad.com
