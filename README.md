# Guia de Mantenimiento de PC

Guia integral de hardware, ensamblaje, mantenimiento y redes de computadoras. Plataforma educativa 100% en espanol, responsiva y con modo oscuro/claro.

## Visita la guia

**[https://apaza-victor.github.io/Guia-de-mantenimiento-de-PC/](https://apaza-victor.github.io/Guia-de-mantenimiento-de-PC/)**

## Contenido

### Ensamblaje
- Herramientas necesarias con descripcion y uso
- Componentes de la PC: CPU, GPU, RAM, motherboard, almacenamiento, fuente, refrigeracion
- Guia paso a paso con instrucciones detalladas
- Cableado interno: conectores SATA, EPS, PCIe, front panel
- Checklist interactivo de ensamblaje

### Mantenimiento
- Mantenimiento preventivo: limpieza interna y externa
- Mantenimiento correctivo: diagnostico de fallas comunes
- Software de diagnostico: HWMonitor, CrystalDiskInfo, MemTest86, FurMark, etc.

### Redes
- Fundamentos TCP/IP y modelo OSI
- Topologias de red: bus, estrella, anillo, mesh, ad-hoc, infraestructura
- Dispositivos de red: NIC, switch, router, hub, repetidor, gateway
- Tipos de cables: UTP, STP, FTP, fibra optica, coaxial
- Direccionamiento IP: rangos privados, CIDR, calculadora interactiva
- Estandares Wi-Fi (802.11n hasta Wi-Fi 7)
- Comandos de diagnostico: ping, ipconfig, tracert, nslookup, netstat, arp, nmap

### Recursos
- Atajos de teclado para Windows y Linux
- Recursos web recomendados

## Caracteristicas

- **Responsiva**: se adapta desde 368px hasta pantallas grandes
- **Modo oscuro/claro**: toggle con persistencia en localStorage
- **Sidebar navegable**: acceso rapido a todas las secciones
- **Animaciones**: transiciones suaves con AOS
- **Calculadora de subred**: herramienta interactiva para calcular rangos IP
- **Checklist interactivo**: marcar pasos completados del ensamblaje
- **Bloques de codigo**: con boton de copiar

## Tecnologias

- HTML5
- CSS3 (custom properties, grid, flexbox)
- JavaScript vanilla
- Bootstrap 5.3 (iconos)
- Bootstrap Icons
- AOS (Animate On Scroll)

## Estructura

```
index.html              → Pagina principal (landing)
pages/
  ensamblaje.html       → Guia de ensamblaje
  mantenimiento.html    → Mantenimiento preventivo y correctivo
  redes.html            → Fundamentos de redes
  recursos.html         → Atajos y recursos web
css/styles.css          → Estilos personalizados
js/script.js            → Funcionalidad interactiva
```
